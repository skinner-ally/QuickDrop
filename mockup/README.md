# Макет: живая копия интерфейса

Полная копия исходников приложения (`mockup/src`) для опытов с дизайном. Работает как настоящее приложение:
граф двигается, записи создаются, настройки сохраняются.

- Запуск: `npm run mockup` из корня проекта → http://localhost:5174
- Свой порт, а значит свой origin и своя IndexedDB: данные основного приложения (порт 5173) сюда не попадают,
  при первом запуске засеваются демо-записи.
- Правьте `mockup/src/styles/*.css`, `mockup/src/index.css` и компоненты в `mockup/src/components/*` — изменения
  видны сразу (HMR), основное приложение не затрагивается.
- Удачные правки переносятся в `src/` вручную. Копия снята с `src/` на момент создания и дальше не синхронизируется.
- Удаление ноды на графе (пункт «Удалить» в меню ноды и `Del`) — сцена «казни»: латник выходит и рубит ноду, в 35 %
  случаев нода уклоняется от первого удара, второй всегда её добивает; запись уходит в корзину в момент удара
  (`lib/graph/smite.ts`, `components/graph/GraphSmite.tsx`). Графика — [pixelfx](https://github.com/patch-gg/pixelfx)
  (MIT): ядро и эффекты в `src/lib/pixelfx-kit` с `LICENSE` и `NOTICE.md`, сама сцена — `fx/moves/node-smite.js`.
  При `prefers-reduced-motion` и больше трёх нод за раз — обычное удаление без сцены.
- В копию не вошли тесты, мини-окно быстрой записи (`capture-main.tsx`), Tauri и PWA-плагин.
- Макет не входит в сборку, typecheck и lint (`tsconfig.app.json` смотрит только на `src`, `.oxlintrc.json` игнорирует `mockup/**`).
