# QuickDrop

QuickDrop — накопитель информации: текст, ссылка, код, идея, файл или изображение сбрасываются в одно место
за секунду. Запись попадает во «Входящие», а потом разбирается: получает категорию, теги, связи, отмечается
избранным и переносится в базу знаний. Структура не задаётся заранее.

Интерфейс на русском. Основная платформа — Windows (настольная версия на Tauri 2). Настольная версия для macOS
и веб-версия (PWA, в том числе для iPhone) собираются, но на устройствах в последнем обновлении не проверялись.
Инструкция для пользователя — `docs/ИНСТРУКЦИЯ.md`, правила оформления интерфейса — `docs/DESIGN.md`.

## Возможности

- **Быстрая запись:** `Ctrl/⌘+Shift+Space`, `Alt+N` или `N` вне полей ввода; строка во «Входящих»; вставка из буфера
  обмена; перетаскивание файлов в окно. Типы записей: текст, ссылка, код, идея, файл, изображение (тип определяется
  по вводу).
- **Входящие → база знаний**, архив, избранное. Категории с цветом, теги, двусторонние связи между записями.
  Режим «Разобрать» и групповые действия.
- **Оформление:** пять сцен («Луг», «Осень», «Бумага», «Зима» — пиксельные; «Классика» — прежний гладкий вид),
  у каждой день и ночь; «Авто» выбирает сцену по времени года. Четыре шрифта текста для пиксельных сцен
  («Округлый», «Строгий», «Мягкий пиксель», «Пиксельный»). Шрифты лежат в сборке, внешних запросов нет.
- **Граф записей:** раздел «Граф». Запись — квадрат цвета своей категории, записи одной категории собираются в
  зону, связи — линии. Сдвиг, масштаб, перетаскивание записей, создание и снятие связей, отбор по поиску, типу,
  тегу, категории, дате и сохранённому поиску, «Разложить заново».
- **Живой фон графа:** лес и пруды по координатам, листопад, лучи света, снег, бабочки, светлячки — в зависимости
  от сцены и времени суток. Останавливается вне графа, при скрытом окне и выключенном «Живом фоне»; при
  `prefers-reduced-motion` картина статична. Графика нарисована в коде приложения.
- **Корзина:** «Удалить» переносит запись в корзину; восстановление, «Удалить навсегда», «Очистить корзину»,
  автоочистка (7, 14, 30, 90 дней, 1 год или не очищать; по умолчанию 30 дней).
- **Markdown** в тексте, идее и заметке к ссылке или файлу: просмотр и исходник, кликабельные задачи, вики-ссылки
  `[[запись]]` (создают связь), таблицы, сноски. Удалённые картинки из Markdown не загружаются. Экспорт записи
  («Скачать как Markdown») и всей базы в папку.
- **Сохранённые поиски:** запрос вместе с фильтрами и разделом закрепляется в боковой панели, раздел «Поиски».
- **Даты:** операторы `date:`, `after:`, `before:`, фильтр «Период» (сегодня, за неделю, за месяц, свой период),
  разделители по дням («Сегодня», «Вчера», дата) при сортировке по дате, точные даты в подробностях записи.
- **Предупреждение о дубле ссылки** при добавлении: «Открыть» уже сохранённую или «Всё равно добавить».
- **Автоматические резервные копии** в выбранную папку по расписанию (настольная версия).
- **Текст PDF в поиске:** текстовый слой PDF извлекается локально и участвует в поиске.
- **Быстрый захват (настольная версия):** мини-окно по глобальному сочетанию из любой программы, значок в трее,
  запуск вместе с системой, один экземпляр приложения.
- **Расширение Chrome** (страница, ссылка или выделенный текст во «Входящие»): папка `extension/` входит в
  установщик (см. «Быстрый захват и расширение»).
- **Распознавание текста** на картинках и сканах PDF через модель со зрением — только при включённом ИИ-помощнике
  (см. «ИИ-помощник и распознавание»). Распознанный текст ищется, правится и попадает в копию и экспорт Markdown.
- Поиск по тексту и операторам, подсветка совпадений, палитра команд `Ctrl/⌘+K`.
- Для ссылок можно подтягивать заголовок страницы. В веб-версии без CORS-прокси заголовок берётся из адреса.
- Резервная копия в JSON: экспорт и импорт в «Настройки → Данные».

## Стек

React 19, TypeScript 7, Vite 8, Tailwind CSS v4, shadcn/ui (на Base UI), Dexie 4 (IndexedDB), MiniSearch, Zustand,
react-markdown и remark-gfm (Markdown), pdf.js (`pdfjs-dist`, текст и растеризация PDF), Vitest с fake-indexeddb,
Tauri 2 (настольная версия), vite-plugin-pwa (Workbox, PWA веб-версии), oxlint.

## Требования

- Node.js 22 или новее.
- Для настольной версии:
  - Rust (stable) через rustup.
  - Предпосылки Tauri для своей ОС: https://v2.tauri.app/start/prerequisites/
  - Windows: Microsoft C++ Build Tools (набор «Разработка классических приложений на C++») и WebView2.
  - macOS: Xcode Command Line Tools (`xcode-select --install`).

## Команды

```bash
npm install            # установка зависимостей
npm run dev            # веб-версия для разработки, http://localhost:5173
npm run typecheck      # проверка типов (tsc -b)
npm run lint           # oxlint
npm test               # тесты (Vitest)
npm run build          # проверка типов и сборка веб-версии в dist/
npm run tauri dev      # настольное приложение в режиме разработки
npm run tauri build    # сборка установщиков настольного приложения
npm run icons          # значки PWA из public/icon.svg (scripts/gen-icons.mjs)
cargo test --manifest-path src-tauri/Cargo.toml   # тесты Rust
node scripts/check-version.mjs [v1.2.3]           # версия в трёх файлах (и совпадение с тегом)
node scripts/gen-extension-icons.mjs              # значки расширения Chrome
```

Перед `cargo test` нужен каталог `dist/`: контекст Tauri собирается из `frontendDist`, поэтому сначала
`npm run build`. Перед сдачей изменений должны проходить `npm run typecheck`, `npm test` и, если менялся Rust,
`cargo test`.

## Что где лежит

- `src/` — интерфейс и логика: `db/` (схема и репозиторий; все записи в БД идут через `db/repo.ts`), `search/`,
  `lib/` (чистая логика и обвязка платформы), `store/`, `hooks/`, `components/`, `views/`, `styles/`.
  Доменная модель — `src/types.ts`.
- `src-tauri/` — оболочка Tauri 2: окна и трей (`shell.rs`), копии и запись в папки (`backup.rs`), приём записей
  от расширения (`ext_server.rs`), загрузка метаданных ссылок (`lib.rs`), права окон (`capabilities/`).
- `extension/` — расширение Chrome (Manifest V3, без сборки).
- `public/` — значки PWA, `theme-init.js` (ранняя тема), `licenses/` (уведомления о стороннем коде).
- `docs/` — инструкция пользователя и правила дизайна. `mockup/` — справочный образец пиксельного вида.
- `CLAUDE.md`, `PROGRESS.md`, `.progress/` — рабочие материалы и состояние разработки.

## Установщики

После `npm run tauri build` установщики лежат в `src-tauri/target/release/bundle/`:
в Windows — в подпапках `msi/` и `nsis/`, в macOS — в `dmg/` и `macos/`.
При сборке под universal-вариант macOS путь другой: `src-tauri/target/universal-apple-darwin/release/bundle/`.
Папка `extension/` кладётся в установщик как ресурс (`bundle.resources` в `src-tauri/tauri.conf.json`).

## Сборка для macOS

Есть два способа.

**На Mac:**

```bash
rustup target add aarch64-apple-darwin x86_64-apple-darwin
npm run tauri build -- --target universal-apple-darwin
```

**Через GitHub Actions:** см. следующий раздел.

В настольной версии для macOS экспорт резервной копии и «Скачать» сохраняют файл сразу в папку «Загрузки»
(без окна выбора), о результате сообщает уведомление. В Windows работает обычная панель загрузок WebView2.

Подпись и нотаризация Apple не настроены. Приложение неподписанное, поэтому при первом запуске macOS
его блокирует. Разрешить запуск можно в «Системные настройки → Конфиденциальность и безопасность»
(кнопка «Всё равно открыть»). Windows-установщик тоже не подписан: SmartScreen покажет предупреждение.

## CI и выпуск версии

Два workflow в `.github/workflows/`:

- `ci.yml` — проверки на каждый push в `main` и на каждый pull request. Задача `web` (Ubuntu): согласованность
  версии, `npm ci`, `npm run typecheck`, `npm test`, `npm run build`. Задача `rust` (Windows): `npm ci`,
  `npm run build`, `cargo test --locked`.
- `release.yml` — запускается при пуше тега `v*` и вручную (`workflow_dispatch`). Сначала задача `web` с теми же
  проверками (версия сверяется с тегом), затем сборка Windows и macOS (universal): в Windows перед сборкой
  выполняется `cargo test`, на macOS тесты Rust не гоняются. Установщики появляются в черновике релиза на
  странице GitHub Releases.

Порядок выпуска версии:

1. Поднять версию одинаково в трёх файлах: `package.json`, `src-tauri/tauri.conf.json`, `src-tauri/Cargo.toml`.
2. Проверить: `node scripts/check-version.mjs v1.2.3` (то же делает workflow).
3. Закоммитить и запушить тег `v1.2.3`.

Тег без поднятой версии workflow отклонит: имя релиза берётся из `tauri.conf.json`, и такой тег дополнил бы
черновик прошлой версии.

## Веб-версия и PWA

Веб-версия собирается командой `npm run build`, результат — папка `dist/`.

1. Разместить содержимое `dist/` на любом статическом хостинге с HTTPS.
2. Открыть адрес в Safari.
3. «Поделиться» → «На экран «Домой»».

Если приложение размещается не в корне сайта, а в подкаталоге (например, GitHub Pages для репозитория:
`https://user.github.io/quickdrop/`), каталог задаётся при сборке:

```bash
VITE_BASE=/quickdrop/ npm run build
```

От него строятся пути в `index.html`, манифест (`start_url`, `scope`, ярлык, `share_target`) и область
service worker. В Git Bash на Windows нужен `MSYS_NO_PATHCONV=1 VITE_BASE=/quickdrop/ npm run build`,
иначе `/quickdrop/` превратится в путь вида `C:/Program Files/Git/quickdrop/`. В PowerShell:
`$env:VITE_BASE='/quickdrop/'; npm run build`. Без переменной сборка рассчитана на корень сайта.

Веб-сборка содержит Content-Security-Policy в `<meta>` (вставляется при `npm run build`; `script-src 'self'`,
WebAssembly не разрешён). Запрет встраивания во фреймы (`frame-ancestors 'none'`) через `<meta>` не работает:
если нужен, его задают заголовком `Content-Security-Policy` на хостинге.

Для проверки в локальной сети:

```bash
npm run build
npx vite preview --host
```

Сервер откроется по HTTP. Установка на экран «Домой» и работа в автономном режиме требуют HTTPS,
поэтому для постоянного использования нужен хостинг с HTTPS.

Веб-версия — PWA (плагин `vite-plugin-pwa`, Workbox):

- установка на экран «Домой»: приложение открывается отдельным окном, без адресной строки;
- офлайн-кэш оболочки приложения через service worker: интерфейс открывается без сети, записи хранятся в IndexedDB;
- автообновление (`registerType: autoUpdate`): новая версия подхватывается тихо, после обновления появляется уведомление «Приложение обновлено». Если в этот момент открыта панель добавления, идёт ввод в поле или открыт диалог, перезагрузка откладывается до сворачивания приложения, а уведомление «Доступна новая версия» предлагает обновиться сразу. Набранный в панели добавления текст сохраняется как черновик по мере ввода и восстанавливается при следующем открытии панели в этой вкладке;
- ярлык «Быстрая запись» (`/?capture=1`) из манифеста; на iOS ярлыки не поддерживаются;
- приём данных через «Поделиться» (`share_target`): работает на Android, на iOS Safari не поддерживается; запись
  получает источник «из «Поделиться»».

Service worker не работает в режиме `npm run dev` (`devOptions` отключены). В сборке Tauri плагин отключён
переменной `TAURI_ENV_PLATFORM`, `sw.js` не создаётся; вместо него в сборку Tauri входит вторая страница
`capture.html` (мини-окно быстрой записи), которой нет в веб-сборке.

Папка `dist/pdfjs/` — декодеры сканов PDF (JBIG2 и JPEG 2000, JS-варианты pdf.js). Они подгружаются только при
растеризации скана для распознавания; в precache service worker не входят (без сети распознавание всё равно
невозможно), WebAssembly не используется. Рядом в `dist/licenses/` лежит `pdfjs-decoders-LICENSE.txt` — лицензии
декодеров. Эти файлы кладёт в сборку плагин `quickdrop:pdf-decoders` из `vite.config.ts`.

## Данные и резервные копии

**Важно.** Данные хранятся локально в IndexedDB каждого устройства и браузера. Между устройствами они
**не синхронизируются**. Чтобы перенести данные, используйте «Настройки → Данные → Экспорт резервной копии»
и затем «Импорт» на другом устройстве.

На iOS Safari сайт, не добавленный на экран «Домой», после длительного неиспользования может потерять
свои данные. Рекомендуется установить приложение на экран «Домой» и периодически делать экспорт.

**Резервная копия** — один JSON-файл (`quickdrop-backup-ГГГГ-ММ-ДД.json`) с записями (в том числе из корзины и с
распознанным текстом), файлами в base64, категориями, положениями нод графа, сохранёнными поисками и частью
настроек (тема, сцена, шрифт, «Живой фон», срок хранения корзины, глобальное сочетание, флаги трея и мини-окна).
Старые копии (формат 1) читаются. Импорт: «Объединить» или «Заменить всё». Копия не больше 480 МБ.

**Не попадают в копию** (и не читаются из чужой копии), чтобы файл копии не мог включить отправку данных в сеть или
записать что-то на этом компьютере: API-ключ, включение ИИ, адрес API и модели, настройки распознавания
(«Распознавать автоматически», «Модель для распознавания»), прокси и загрузка заголовков ссылок, папки и расписание
автокопий, настройки приёма от расширения (включая токен). «Удалить все данные» стирает записи, файлы, категории,
ключ и адреса ИИ, прокси и токен расширения и выключает приём от расширения.

**Автоматические копии** (только настольная версия, «Настройки → Копии и экспорт в папку»): папка выбирается
системным диалогом (приложение пишет только в подтверждённые папки), периодичность «Выключено / Каждый день / Каждую
неделю», «Хранить копий» от 1 до 100 (по умолчанию 10), кнопка «Сделать копию сейчас». Файлы называются
`quickdrop-backup-ГГГГММДД-ЧЧММСС.json`, запись атомарная; удаляются только старые собственные копии, чужие файлы в
папке не трогаются. Проверка срока — через 30 секунд после запуска и раз в час, пока приложение работает.

**Экспорт в Markdown** (настольная версия): «Экспортировать в Markdown» выгружает каждую запись файлом `.md` с
front matter (id, title, type, status, category, tags, favorite, url, created, updated, source), вложения — в папку
`attachments/`. Вики-ссылки и связи переписываются в `[[имя файла]]`, распознанный текст — раздел
`## Распознанный текст`, связи — раздел `## Связанные`. Файлы с теми же именами перезаписываются, остальное в папке
не трогается; записи из корзины не выгружаются. Есть прогресс и отмена. Отдельная запись (текст, идея, код, ссылка) —
пункт меню «Скачать как Markdown» (работает и в браузере).

## Горячие клавиши

Работают внутри открытого приложения; сочетания проверяются по физической клавише, поэтому работают в любой
раскладке. На Mac вместо `Ctrl` — `⌘`.

| Действие | Клавиши |
|---|---|
| Быстрая запись | `Ctrl/⌘+Shift+Space`, `Alt+N`, `N` (вне полей ввода) |
| Поиск | `Ctrl/⌘+K` (палитра команд) или `/` (поле поиска) |
| Разделы: Входящие, База знаний, Избранное, Архив, Граф | `1`, `2`, `3`, `4`, `5` (Корзина — без цифры) |
| Закрыть панель или детали | `Esc` |
| Добавить содержимое буфера (вне полей ввода) | `Ctrl/⌘+V` |
| В списке: вниз / вверх | `J` или `↓` / `K` или `↑` |
| В списке: открыть | `Enter` или `O` |
| В списке: в базу знаний (из архива — вернуть) | `E` |
| В списке: в архив (из архива — вернуть) | `A` |
| В списке: в избранное | `F` |
| В списке: отметить / отметить все | `X` / `Ctrl+A` |
| В списке: в корзину | `Del` |
| В корзине: восстановить / удалить навсегда | `E` / `Del` |
| «Разобрать»: в базу знаний / в архив | `E` или `Ctrl+Enter` / `A` |
| «Разобрать»: пропустить / назад | `→` или `S` / `←` |
| «Разобрать»: избранное / удалить | `F` / `Del` |
| На графе: переход между записями | стрелки |
| На графе: по связям записи | `Tab` |
| На графе: открыть запись | `Enter` |
| На графе: категория / связать | `E` / `L` |
| На графе: в архив / в избранное | `A` / `F` |
| На графе: в корзину или убрать выбранную связь | `Del` |
| На графе: масштаб / весь граф / сдвиг | `+` и `−` / `0` / `Shift+стрелки` |
| На графе: снять курсор | `Esc` |
| В панели добавления: сохранить / ещё одну | `Enter` (однострочный текст) или `Ctrl+Enter` / `Ctrl+Shift+Enter` |

На графе колесо мыши меняет масштаб (ступени 12,5 / 25 / 50 / 75 / 100 / 150 / 200 %), `Shift`+колесо и перетаскивание
фона сдвигают вид; подписи записей видны от 100 %. В настольной версии `Ctrl/⌘+Shift+Space` глобально: из любой
программы открывает мини-окно быстрой записи (повторное нажатие прячет его), а при выключенном мини-окне поднимает
главное окно и открывает добавление. Сочетание меняется в «Настройки → Быстрый захват»; новое сочетание применяется
сразу. Если оно занято другой программой или записано неверно, появляется ошибка и остаётся прежнее.

## Быстрый захват и расширение (настольная версия)

«Настройки → Быстрый захват»:

- «Мини-окно быстрой записи» (по умолчанию включено): глобальное сочетание открывает маленькое окно поверх других
  программ; выключено — поднимается главное окно с панелью добавления.
- «Глобальное сочетание» (по умолчанию `CommandOrControl+Shift+Space`).
- «Сворачивать в трей при закрытии» (по умолчанию выключено: крестик закрывает приложение).
- «Запускать вместе с системой» (по умолчанию выключено): запись только в `HKCU\...\Run`, приложение стартует
  свёрнутым в трей; в отладочной сборке недоступно.
- Значок в трее: левый клик открывает главное окно; меню «Открыть QuickDrop», «Быстрая запись», «Выход».
- Один экземпляр: повторный запуск поднимает уже работающее окно.

**Расширение Chrome** (`extension/`, Manifest V3, Chrome 116+ и другие браузеры на Chromium): кнопка, контекстное
меню и `Alt+Shift+Q` отправляют страницу, ссылку или выделенный текст во «Входящие». Папка `extension/` входит в
установщик как ресурс; её путь показан в «Настройки → Быстрый захват» (кнопки «Показать папку» и «Копировать
путь»). Установка:

1. Включить «Принимать записи от расширения» (по умолчанию выключено) — появятся порт (по умолчанию 47821) и токен.
2. В Chrome открыть `chrome://extensions`, включить «Режим разработчика», нажать «Загрузить распакованное
   расширение» и выбрать папку расширения.
3. В настройках расширения указать порт и токен, нажать «Сохранить» и «Проверить соединение».

После обновления QuickDrop нажать «Обновить» на карточке расширения в `chrome://extensions`.

QuickDrop слушает только `127.0.0.1` и только пока приём включён; без верного токена запросы отклоняются, проверяются
заголовки `Host` и `Origin`, размеры ограничены (адрес до 2048 символов, выделенный текст до 500 000). Расширение
только отправляет записи. **Принятый риск:** расширение не может проверить, кто отвечает на порту. Пока QuickDrop
закрыт или приём выключен, порт может занять другая программа и получить токен и отправляемое; на компьютере с
несколькими пользователями выберите нестандартный порт и не пользуйтесь расширением, когда QuickDrop закрыт.
Подробности — `extension/README.md`.

## Поиск

Операторы можно комбинировать с обычным текстом, значения через запятую (`type:link,code`). Регистр и `ё`/`е` не
важны. Неизвестный оператор или значение остаётся обычным текстом.

| Оператор | Что находит |
|---|---|
| `tag:слово`, `tags:слово`, `тег:слово`, `#слово` | Запись с тегом (для тега с пробелом — `#"мой тег"`) |
| `type:` / `тип:` | Тип: `text` (`txt`, `note`, `текст`, `заметка`), `link` (`url`, `ссылка`), `code` (`snippet`, `код`), `idea` (`идея`), `file` (`файл`), `image` (`img`, `photo`, `изображение`, `картинка`, `фото`) |
| `is:fav` (`favorite`, `star`, `избранное`) | Избранное |
| `is:inbox` (`new`, `входящие`), `is:library` (`lib`, `база`, `библиотека`), `is:archive` (`архив`) | Статус записи |
| `is:untagged` (`notags`, `без-тегов`) | Без тегов и без категории |
| `is:trash` (`trashed`, `deleted`, `bin`, `корзина`) | Записи из корзины |
| `has:file` (`attachment`, `файл`, `вложение`) | Файлы и изображения |
| `has:image` (`img`, `фото`, `картинка`, `изображение`), `has:link` (`url`, `ссылка`) | Изображения; ссылки |
| `cat:имя` (`category:`, `кат:`, `категория:`) | Категория; для имени с пробелами — `cat:"мои проекты"`; `cat:none` (`нет`, `без`, `"без категории"`) — записи без категории |
| `date:`, `дата:` | Дата создания записи (см. ниже) |
| `after:` (`since:`, `после:`) | Создано не раньше начала указанной даты или периода |
| `before:` (`until:`, `до:`) | Создано не позже конца указанной даты или периода |
| `"точная фраза"`, `«точная фраза»` | Фраза целиком |

Значение дат (локальное время, границы включительно): `2026-11-10`, `10.11.2026`, `2026-11` (месяц), `11.2026`,
`2026` (год); `today`/`сегодня`, `yesterday`/`вчера`, `week`/`неделя` (последние 7 дней, включая сегодня),
`month`/`месяц` (последние 30 дней), `year`/`год` (365 дней); для `date:` ещё диапазон `2026-10-01..2026-10-31`.
Несколько операторов дат пересекаются. Неверная дата остаётся обычным текстом.

Поиск идёт по заголовку, содержимому, адресу ссылки, тегам, имени файла, данным страницы ссылки, названию категории
и тексту вложения (текстовый слой PDF, распознанный текст). Он префиксный и нечёткий (для слов от 4 букв). Индекс
хранится в памяти и пересобирается при изменении записей; в индекс берутся первые 100 000 знаков содержимого и
текста вложения.

## ИИ-помощник и распознавание (необязательно)

Выключено по умолчанию: пока «Включить ИИ-помощника» не включено и не указан ключ, никакие запросы к ИИ не
отправляются. Включается в «Настройки → ИИ-помощник». Работает с любым OpenAI-совместимым API (`/chat/completions`);
есть пресеты DeepSeek и OpenAI, адрес API и модель можно задать вручную. Пресет DeepSeek (`deepseek-chat`)
изображения не принимает: для распознавания укажите модель со зрением в поле «Модель для распознавания».

Что и куда уходит (адрес — «Адрес API», запросы идут напрямую провайдеру, без посредников):

| Действие | Что отправляется |
|---|---|
| Подсказка заголовка и тегов (кнопка в подробностях записи и в режиме «Разобрать») | Тип записи, адрес и данные страницы ссылки, заголовок, имя файла, язык кода, первые 6000 знаков содержимого. Файлы не отправляются; распознанный текст в подсказку не входит |
| Распознавание картинки | Сама картинка, уменьшенная до 2000 px по большей стороне и сжатая (JPEG или PNG до 4 МБ) |
| Распознавание скана PDF | Первые 5 страниц, каждая отдельным запросом картинкой |
| «Проверить подключение», «Проверить распознавание» | Проверочная заметка; проверочная картинка с надписью «QuickDrop 2468» |

PDF с текстовым слоем текст отдаёт локально, без сети (до 200 страниц, 200 000 знаков, 50 МБ, 30 секунд на файл).

**Распознавание.** Кнопка «Распознать текст» в подробностях записи-картинки или скана PDF; рядом всегда написано,
что и на какой хост уйдёт. Запись в корзине не распознаётся. Результат — раздел «Распознанный текст» (по умолчанию
свёрнут): показываются первые 20 000 знаков, правка доступна до 50 000, есть «Копировать», «Изменить», «Очистить» (с
«Отменить») и «Распознать заново». Текст пишется в `ocrText`, `updatedAt` записи не меняется.

Пределы: исходная картинка до 30 МБ, меньше 24 px по стороне не распознаётся, у PDF — первые 5 страниц. Один запрос
за раз; ручной запуск идёт вне очереди автораспознавания. Ошибки разбираются по виду: неверный ключ, модель без зрения
или неверный адрес останавливают автораспознавание; сбой самого изображения ставит отметку «пробовали» и не
повторяется; сеть, лимит (429) и сбой сервиса отметки не ставят.

**Автораспознавание** («Распознавать автоматически», по умолчанию выключено; доступно, когда ИИ настроен): новые
картинки и сканы PDF отправляются без вопроса сразу после добавления. Касается только записей, созданных после
включения; накопленное распознаётся кнопкой. Не чаще одного запроса в 3 секунды, не больше 100 запросов за сеанс
(страница PDF — запрос). После ответа 429 — пауза на минуту, после трёх временных ошибок подряд — на 10 минут; о
каждой остановке одно сообщение. Записи из мини-окна подхватывает главное окно (в течение минуты после возврата
фокуса); само мини-окно не распознаёт. Выключение ИИ действует и на запросы, уже стоящие в очереди.

Ключ API хранится только локально в этом браузере или приложении и не попадает в копию. Адрес API должен начинаться с
`https://`; `http://` допускается только для локальной модели (`localhost`, `127.0.0.1`, `[::1]`).

**Сетевые запросы приложения.** Кроме загрузки метаданных ссылок («Настройки → Ссылки»; в настольной версии —
командой Rust `fetch_link_meta`, которая не ходит во внутреннюю сеть с публичной ссылки; в вебе — прямой запрос и,
если задан, свой CORS-прокси) и явно включённого ИИ приложение сетевых запросов не делает. Удалённые картинки ссылок
показываются только при включённой загрузке заголовков, картинки из Markdown не загружаются никогда. Локальный сервер
расширения только принимает записи на `127.0.0.1`.
