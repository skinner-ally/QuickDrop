# pixelfx в QuickDrop

Небольшая часть библиотеки **pixelfx** (MIT, Copyright (c) 2026 Patch, Copyright (c) 2026 Hugo Duprez) —
https://www.spritefusion.com/pixel-art-vfx . Текст лицензии — `LICENSE` рядом; в `math.ts` полный текст лицензии продублирован в шапке `/*! … */`, в остальных файлах —
короткая шапка с отсылкой к `LICENSE`. Шапки нужны только для исходников; на сборку не рассчитываем: в сборку (веб и установщик)
лицензия идёт отдельным файлом `public/licenses/pixelfx-LICENSE.txt`.

Ядро pixelfx (движок эффектов, два буфера, актёры) **не перенесено**: фону графа нужны только помощники и два рецепта.

## Что откуда

| Файл | Откуда |
|---|---|
| `math.ts` | `core/math.js` — `TAU`, `clamp`, `wrap`, `hash`, `rand` (хеш и случайность по целым: тот же алгоритм, те же числа) |
| `color.ts` | `core/color.js` — `hex`, `mix`, `fit` (поверх `hexColor` и `mixColor` из `lib/ambient/raster.ts`) |
| `trips.ts` | `fx/weather/_lib.js` — `trips` (падающие частицы петли) и `bayer` (порог упорядоченного смешения 4×4) |
| `leaves.ts` | листопад: переработка рецепта pixelfx `weather/falling-leaves`, взята из `mockup/weather.js` |
| `rays.ts` | солнечные лучи и пылинки: переработка рецепта pixelfx `weather/god-rays`, взята из `mockup/weather.js` |

`mockup/weather.js` сам переработан из этих двух рецептов под вид сверху и произвольный размер холста; в копии
`mockup/pixelfx` самих рецептов (`falling-leaves`, `god-rays`) нет.

## Что изменено

- TypeScript со строгими типами вместо JavaScript.
- Один растр (`Uint32Array` в раскладке ImageData, `lib/ambient/types.ts: Raster`) вместо двух буферов «цвет и свет»:
  свечение (`glow`) смешивается обычной альфой.
- Вид сверху: у каждого листа своя точка приземления; листья не ложатся на ноды (рядом с нодой лист бледнее или не
  рисуется), пылинки не рисуются рядом с нодой.
- Лучи — через таблицу по углу: свет зависит только от угла пикселя к источнику, поэтому на размер растра один раз
  считаются номер угла и затухание, а на тик — таблица на 1024 значения и один проход по пикселям. Ступени света
  светлые, альфа не выше `AMBIENT_OVERLAY_MAX.alpha`.

Снег, светлячки и бабочки — собственный код проекта (`src/lib/ambient/effects/`), pixelfx не используют.
