# QuickDrop — инструкция пользователя

QuickDrop — одно место, куда можно быстро сбросить что угодно: ссылку, текст, фрагмент кода, идею, файл или
картинку. Раскладывать по папкам заранее не нужно. Всё новое попадает во «Входящие», а потом вы разбираете
записи: назначаете категорию и теги, связываете между собой и переносите в базу знаний.

## Главная схема работы

1. **Сбросить.** Нажали горячую клавишу, вставили или набрали — запись во «Входящих».
2. **Разобрать.** Когда есть время, проходите «Входящие»: нужное — в базу знаний, лишнее — в архив или в корзину.
3. **Найти.** Поиск по содержимому, фильтры по типу, категории, тегам и датам; граф связей между записями.

Запись всегда находится в одном из состояний:

| Состояние | Что это |
|---|---|
| Входящие | Новое, ещё не разобранное |
| База знаний | Разобранное и оставленное насовсем |
| Архив | Убрано с глаз, но не удалено |
| Корзина | Удалено; лежит, пока не истечёт срок или вы не удалите насовсем |

«Избранное» — это не отдельное состояние, а отметка-звезда: избранной может быть запись и из входящих,
и из базы знаний.

## Запуск

- **Windows.** Установите `QuickDrop_<версия>_x64-setup.exe` и запускайте из меню «Пуск». Установщик
  не подписан, поэтому SmartScreen покажет предупреждение: «Подробнее» → «Выполнить в любом случае».
  В настольной версии есть значок в трее и запуск вместе с системой — см. «Быстрый захват и расширение».
- **Браузер.** Откройте адрес, по которому размещена веб-версия.
- **iPhone.** Откройте веб-версию в Safari, затем «Поделиться» → «На экран „Домой“». Приложение появится
  отдельной иконкой и будет открываться без адресной строки.

При первом запуске в приложении лежат демонстрационные записи, чтобы было видно, как всё выглядит.
Убрать их можно в «Настройки → Данные → Удалить все данные».

## Как добавить запись

### Панель «Быстрая запись»

Открывается любым способом:

- `Ctrl+Shift+Space` (на Mac `⌘+Shift+Space`);
- `Alt+N`;
- `N`, если курсор не стоит в поле ввода;
- кнопка «Добавить» слева вверху (на телефоне — круглая кнопка внизу справа).

Дальше вставьте или наберите содержимое и нажмите `Enter`. Больше ничего заполнять не обязательно.

| Действие | Клавиши |
|---|---|
| Сохранить | `Enter` для однострочного текста, `Ctrl+Enter` — всегда |
| Перенос строки | `Shift+Enter` |
| Сохранить и добавить ещё одну | `Ctrl+Shift+Enter` |
| Закрыть без сохранения | `Esc` |

Для кода и многострочного текста простой `Enter` переносит строку, сохранять нужно через `Ctrl+Enter`.
На телефоне `Enter` всегда переносит строку, сохранение — кнопкой «Сохранить».

Если закрыть панель с набранным текстом, он останется черновиком и вернётся при следующем открытии
(«Черновик восстановлен», кнопка «Очистить»). Если к записи прикреплены файлы, при закрытии появится вопрос
«Закрыть / Остаться»: файлы в черновике не сохраняются.

### Мини-окно из любой программы (Windows)

В установленной версии для Windows `Ctrl+Shift+Space` работает **из любой программы**: поверх всего появляется
маленькое окно «Быстрая запись» (на том мониторе, где курсор). Вставьте или наберите, `Enter` — запись сохранена,
окно спряталось. `Esc`, потеря фокуса или повторное нажатие сочетания тоже прячут окно. Запись видна в главном
окне сразу, перезапускать не нужно. Мини-окно умеет всё то же, что панель: тип, заголовок, категория, теги, файлы,
избранное, «Сразу в базу знаний». Выключить его и вернуть старое поведение (поднимается главное окно с панелью)
можно в «Настройки → Быстрый захват → Мини-окно быстрой записи». Сочетание там же меняется.

### Тип записи определяется сам

| Что ввели | Каким типом станет |
|---|---|
| Один адрес сайта | Ссылка |
| Фрагмент программы | Код (язык тоже подбирается) |
| Обычный текст | Текст |
| Файл | Файл или изображение |

Тип «Идея» автоматически не ставится — выберите его сами в ряду переключателей под полем. Там же можно
исправить тип, если он определился неверно (повторный клик возвращает автоопределение).

### Необязательные поля

Под полем ввода есть заголовок, категория и теги. Ещё два переключателя:

- **Сразу в базу знаний** — запись минует «Входящие».
- **Звезда** — сразу отметить избранным.

### Предупреждение о дубле ссылки

Если адрес уже сохранён, под полем появится «Такая ссылка уже есть: …» с кнопками «Открыть» и «Всё равно добавить».
Адреса сравниваются без учёта `http`/`https`, `www.` и меток слежения (`utm_*`, `fbclid` и подобных).
Запись в архиве считается дублем, запись в корзине — нет.

### Другие способы

- **Вставка из буфера.** Нажмите `Ctrl+V`, когда курсор не стоит в поле ввода: панель откроется уже
  с содержимым буфера, будь то текст или скопированная картинка.
- **Перетаскивание.** Перетащите файлы в окно приложения.
- **Скрепка** в панели добавления — выбрать файлы с диска. Каждый файл становится отдельной записью.
- **Строка «Быстрая запись»** вверху «Входящих»: набрали, `Enter` — и запись сохранена без открытия панели.
- **Расширение Chrome** — страница, ссылка или выделенный текст прямо из браузера; см. «Быстрый захват и расширение».
- **«Поделиться» на Android** (веб-версия, установленная как приложение): запись получает источник «из «Поделиться»».

Один файл может быть не больше 100 МБ.

## Разбор входящих

«Входящие» — главная страница. Счётчик рядом с названием показывает, сколько записей ждут разбора.

### Клавишами в списке

Работают, когда курсор не стоит в поле ввода. Текущая строка отмечена цветной полосой слева.

| Клавиша | Действие |
|---|---|
| `J` или `↓` | К следующей записи |
| `K` или `↑` | К предыдущей |
| `Enter` или `O` | Открыть подробности |
| `E` | В базу знаний (из архива и корзины — вернуть) |
| `A` | В архив (из архива — вернуть) |
| `F` | В избранное / убрать |
| `X` | Отметить запись для группового действия |
| `Ctrl+A` | Отметить все видимые |
| `Del` | В корзину |

После `E`, `A` и `Del` курсор сам переходит на следующую запись, так что входящие можно разобрать, не трогая мышь.

### Режим «Разобрать»

Кнопка «Разобрать» справа вверху открывает записи по одной, крупно. Под записью — категория и теги,
изменения сохраняются сразу.

| Клавиша | Действие |
|---|---|
| `E` или `Ctrl+Enter` | В базу знаний |
| `A` | В архив |
| `→` или `S` | Пропустить |
| `←` | Назад |
| `F` | Избранное |
| `Del` | В корзину |

В конце показывается сводка: сколько записей ушло в базу, в архив и сколько удалено.

### Групповые действия

Отметьте несколько записей галочками (или `X`, или `Shift`+клик для диапазона). Внизу появится панель:
в базу знаний, в архив, назначить категорию, добавить теги, удалить.

### Отмена

После переноса, архивации и удаления внизу на несколько секунд появляется уведомление с кнопкой «Отменить».

## Подробности записи

Клик по записи или `Enter` открывает панель справа (на телефоне — на весь экран). В ней можно:

- **Править заголовок и содержимое** — кликните по тексту. Изменения сохраняются сами.
- **Сменить тип** текста, идеи и кода — кнопка с названием типа в шапке панели.
- **Назначить категорию и теги.** Новую категорию можно создать прямо из поля выбора.
- **Связать с другой записью** — кнопка «Связать…», затем найдите нужную запись. Связь двусторонняя:
  она видна в обеих записях, по ней можно перейти. Ниже предлагаются «Похожие» записи (с общими тегами).
- **Для ссылки** — открыть, скопировать адрес, обновить данные страницы, добавить заметку.
- **Для файла и изображения** — посмотреть, скачать, добавить заметку, получить распознанный текст (см. ниже).
  Картинка по клику открывается крупно.
- **Для кода** — сменить язык подсветки, скопировать.
- **Меню «Действия с записью»** — открыть ссылку, копировать, в избранное, в базу знаний, вернуть во входящие,
  в архив, скачать, «Скачать как Markdown» (для текста, идеи, кода и ссылки), удалить.

Внизу панели — «Создано», «Изменено», «Обработано», «Удалено» с точной датой и временем и «Источник» записи
(вручную, вставка, перетаскивание, импорт, из браузера, из «Поделиться»). В списках у записи показано относительное
время («5 мин назад», «вчера»); точная дата — во всплывающей подсказке.

Закрыть панель — `Esc`.

### Markdown и связи по названию

Текст, идея и заметка к ссылке или файлу понимают Markdown: заголовки, списки, цитаты, таблицы, код, сноски.
Переключатель «Просмотр / Исходник» стоит под текстом справа, рядом с «Изменить» (у файлов .md — над предпросмотром), и один на всё приложение. В просмотре:

- **Задачи** `- [ ]` отмечаются кликом по флажку — исходный текст обновляется сам.
- **Вики-ссылки** `[[Название записи]]` (или `[[Название|подпись]]`) показываются ссылками. Когда вы сохраняете
  текст, для каждой найденной записи с таким названием создаётся связь. Клик по ссылке открывает запись.
  Не найденная запись показывается без связи.
- **Ссылки** открываются в браузере. **Картинки** по адресу из Markdown не загружаются — вместо них ссылка.
- Очень длинный текст показывается исходником.

## Распознанный текст

У картинок и PDF есть раздел «Распознанный текст» — текст, найденный на изображении или в PDF. Он участвует в
поиске (в списке под записью виден фрагмент с подсветкой), попадает в резервную копию и в экспорт Markdown
(раздел `## Распознанный текст`).

**PDF с текстовым слоем.** Текст извлекается сам, на этом же компьютере, без интернета: при добавлении файла и
в фоне для PDF, добавленных раньше. Предел: до 200 страниц, 50 МБ, 200 000 знаков, 30 секунд на файл. Если слоя
нет или он слишком мал (скан), раздел покажет примечание. Кнопка «Извлечь текст» запускает извлечение вручную,
«Извлечь заново» — повторно.

**Картинки и сканы PDF.** Это распознаёт модель со зрением — только если вы включили ИИ-помощника
(«Настройки → ИИ-помощник») и указали ключ. По умолчанию ИИ выключен, и тогда у картинки блока распознавания нет, а
ничего никуда не отправляется. Что делает кнопка:

1. Откройте запись-картинку (или скан PDF) и нажмите **«Распознать текст»**. Рядом всегда написано, куда уйдёт
   изображение: «Изображение будет отправлено на {адрес сервиса}» (для PDF — «Первые страницы (до 5) будут отправлены
   картинками на …»).
2. Пока идёт запрос, видно «В очереди…», «Распознаётся…» (у PDF — «страница N из M») и кнопка «Отменить».
3. Готовый текст появляется в разделе «Распознанный текст» (он свёрнут: кликните по заголовку, справа число знаков).
   Если текста на изображении нет, будет «Текст не найден» и кнопка «Распознать заново».

Что вы можете сделать с текстом: «Копировать»; «Изменить» (правка до 50 000 знаков; стёртый целиком текст равен
очистке); «Очистить» (появится «Отменить»); «Распознать заново». В интерфейсе показываются первые 20 000 знаков,
остальное — по кнопке «Показать весь текст». Запись из корзины можно только смотреть и копировать.

**Что именно отправляется.** Одно изображение, предварительно уменьшенное до 2000 px по большей стороне и сжатое
(JPEG или PNG до 4 МБ); у PDF — первые 5 страниц, каждая отдельной картинкой. Больше ничего: текст и заголовок записи
в этот запрос не входят. Адрес сервиса — тот, что указан в «Настройки → ИИ-помощник → Адрес API».

**Пределы.** Исходная картинка до 30 МБ; изображения меньше 24 px по стороне не распознаются; у скана PDF
распознаются только первые 5 страниц. Распознавание идёт по одной записи за раз.

**Автораспознавание.** «Настройки → ИИ-помощник → Распознавать автоматически» (по умолчанию выключено): новые
картинки и сканы PDF отправляются сразу после добавления, без вопроса. Это касается только записей, добавленных
после включения; более старые распознаются кнопкой в подробностях. Приложение ограничивает себя: не чаще одного
запроса в 3 секунды и не больше 100 запросов за запуск (страница PDF — один запрос); при ошибке настроек
(ключ, модель) автораспознавание останавливается с сообщением, при лимите провайдера делает паузу. Картинки, добавленные
через мини-окно, подхватит главное окно (в течение минуты после возврата к нему). Если выключить ИИ-помощника,
запросы прекращаются сразу, в том числе уже стоящие в очереди.

## Категории и теги

**Категория** у записи одна. Это крупное деление: «Работа», «Обучение», «Идеи». У каждой свой цвет.

**Тегов** может быть сколько угодно. Это мелкие метки: `#react`, `#встречи`. Теги пишутся строчными буквами,
пробел заменяется дефисом. При вводе появляются подсказки из уже существующих тегов.

Оба списка показаны в боковой панели слева: клик по категории или тегу открывает базу знаний с этим фильтром
(на графе — приглушает остальные записи, см. «Граф»).

Управление — в «Настройки → Категории» и «Настройки → Теги»: переименование, цвет, порядок, удаление.
Если переименовать тег в уже существующий, они сольются. При удалении категории записи остаются,
но теряют категорию.

## Поиск

Поле поиска вверху. Перейти в него — `/`. Поиск идёт по заголовку, содержимому, адресу ссылки, тегам,
имени файла, данным страницы ссылки, названию категории и тексту вложений (текст PDF, распознанный текст).
Он прощает опечатки и находит по началу слова; регистр и `ё`/`е` не важны.

Поиск фильтрует текущий раздел. Чтобы искать по всему сразу, откройте палитру команд — `Ctrl+K`.

### Операторы

Можно сочетать с обычным текстом, например: `индексы type:ссылка tag:базы-данных after:2026-10-01`.
Значения можно перечислять через запятую: `type:ссылка,код`.

| Оператор | Что находит |
|---|---|
| `tag:слово`, `тег:слово` или `#слово` | Записи с тегом (с пробелом — `#"мой тег"`) |
| `type:ссылка`, `тип:ссылка` | Записи типа: `текст`, `ссылка`, `код`, `идея`, `файл`, `изображение` (можно и по-английски) |
| `is:fav` (или `is:избранное`) | Избранное |
| `is:inbox`, `is:library`, `is:archive` (или `is:входящие`, `is:база`, `is:архив`) | По состоянию |
| `is:untagged` | Без тегов и без категории |
| `is:trash` (или `is:корзина`) | Записи из корзины |
| `has:file` | С файлом или изображением |
| `has:image`, `has:link` | Изображения; ссылки |
| `cat:работа` | В категории; имя с пробелами — в кавычках: `cat:"мои проекты"`; `cat:none` — без категории |
| `date:…` | Дата создания записи |
| `after:…`, `before:…` | Создано не раньше / не позже даты |
| `"точная фраза"` | Фразу целиком |

Даты (по вашему времени): `date:2026-11-10`, `date:10.11.2026`, `date:2026-11` (месяц), `date:2026` (год);
`date:сегодня`, `date:вчера`, `date:неделя` (последние 7 дней), `date:месяц` (последние 30 дней), `date:год`;
диапазон — `date:2026-10-01..2026-10-31`. `after:2026-10` — с начала октября, `before:2026-10` — до конца октября.
Несколько операторов дат действуют вместе. Русские псевдонимы: `дата:`, `после:`, `до:`.

### Фильтры

Над списком — строка фильтров: типы, категория, теги, «Без тегов и категории», «Период». Справа — сортировка
(«Сначала новые», «Сначала старые», «Недавно изменённые», «По названию») и переключатель «Список / Карточки».
«Период» предлагает «Всё время», «Сегодня», «За неделю», «За месяц» или свой период «С … По …». Когда фильтры
включены, под ними появляются активные фильтры с «Сбросить фильтры». При сортировке по дате список разбит
разделителями по дням («Сегодня», «Вчера», дата).

### Сохранённые поиски

Когда включён поиск или фильтры, в строке активных фильтров появляется «Сохранить поиск»: введите название —
запрос вместе с фильтрами и разделом закрепится в боковой панели, в блоке «Поиски». Клик применяет его;
меню у поиска — «Переименовать», «Выше», «Ниже», «Удалить» (с «Отменить»). Сохранённый поиск — обычная строка
запроса с операторами, его же можно набрать вручную.

### Палитра команд

`Ctrl+K` открывает окно, из которого можно найти любую запись в любом разделе, перейти в раздел, создать запись,
применить сохранённый поиск, категорию или тег, очистить корзину, сменить тему и сцену, а на графе — показать весь
граф, разложить заново или показать архив. Стрелки — выбрать, `Enter` — открыть, `Esc` — закрыть.

## Разделы

| Раздел | Клавиша | Что в нём |
|---|---|---|
| Входящие | `1` | Новое и неразобранное |
| База знаний | `2` | Всё разобранное |
| Избранное | `3` | Записи со звездой |
| Архив | `4` | Убранное; отсюда запись можно вернуть |
| Граф | `5` | Все записи квадратами по зонам категорий, связи линиями |
| Корзина | — | Удалённое; восстановление и удаление навсегда |
| Настройки | — | Оформление, категории, теги, ссылки, ИИ, клавиши, быстрый захват, данные, копии |

## Граф

Раздел «Граф» (`5`) показывает все записи сразу. Каждая запись — квадрат цвета своей категории (запись без
категории — нейтрального цвета), записи одной категории собираются в одну **зону**, связи рисуются линиями.
Метка в углу квадрата отмечает запись из «Входящих». Архивные записи приглушены, а переключатель «Показывать архив»
внизу слева скрывает их совсем. Записи из корзины на графе не показываются; восстановленная запись возвращается на
своё место.

- **Сдвиг и масштаб.** Тяните фон, чтобы сдвинуть вид; колесо мыши меняет масштаб (12,5 — 200 %), `Shift`+колесо
  сдвигает вид вбок. Кнопки внизу слева: «Уменьшить», «Увеличить», «Весь граф» (`0`), «Разложить заново»,
  «Показывать архив». Подписи записей видны от 100 %; на меньшем масштабе заголовок виден во всплывающей подсказке.
  На телефоне — сдвиг пальцем и щипок двумя пальцами.
- **Открыть запись** — клик или `Enter`; двойной клик по записи приближает её и открывает подробности, по пустому
  месту — приближает вид.
- **Перенести запись** — перетащите её: новое место запоминается. Смена категории (`E` или «Категория…» в меню
  записи, цифры `1`–`9`, `0` — без категории) переносит запись в зону новой категории. «Разложить заново»
  пересчитывает расположение всех записей (с «Отменить»).
- **Связать записи** — `L`, пункт «Связать с…» в меню записи (правая кнопка мыши) и щелчок по второй записи;
  потянуть значок связи у выбранной записи к другой (в окне шире 1100 px); перетащить запись на другую с
  зажатым `Shift`. **Убрать связь** — щёлкните по линии и нажмите «Убрать связь» (или `Del`).
- **Клавиатура.** Стрелки — переход между записями, `Tab` — по связям записи, `Enter` — открыть, `A` — в архив,
  `F` — в избранное, `Del` — в корзину, `+` и `−` — масштаб, `Shift`+стрелки — сдвиг, `Esc` — снять курсор.
- **Отбор.** Поиск вверху, фильтры типа, категории, тегов и периода, сохранённые поиски действуют на граф так же,
  как на списки, но не убирают записи, а приглушают неподходящие; в заголовке виден счёт «подходит N из M».
  Боковая панель на графе — легенда: категории и теги с числом записей графа, клик приглушает остальные.

### Живой фон

В пиксельных сценах граф лежит на «живом фоне»: лес и пруды, которые рисуются по координатам и не растут под
записями. «Луг» — лучи света и бабочки днём, светлячки ночью; «Осень» — листопад и лучи; «Зима» — снег; «Бумага» —
без пейзажа; в «Классике» фона нет. Фон останавливается, когда открыт другой раздел или окно скрыто; при включённой в
системе настройке «уменьшить движение» остаётся статичная картинка. Выключатель — «Настройки → Оформление → Живой фон».

## Корзина

«Удалить» (`Del`, меню записи, массовое действие) переносит запись в **корзину**, а не стирает её: внизу появляется
«В корзине» с кнопкой «Отменить». Корзина — отдельный раздел в боковой панели (со счётчиком).

- **Просмотр.** Записи в корзине открываются только для чтения (можно копировать и скачать файл). Вверху подробностей
  показано, когда запись удалена и когда будет удалена окончательно.
- **Восстановить** — `E`, меню записи или «Восстановить» в подробностях: запись возвращается в прежнее состояние
  (Входящие, База знаний, Архив) со всеми связями.
- **Удалить навсегда** — `Del` в корзине, меню записи или кнопка в подробностях; перед удалением спросят
  подтверждение. Это нельзя отменить.
- **«Очистить корзину»** — кнопка в заголовке раздела и в «Настройки → Данные»: удаляет все записи корзины насовсем
  (с подтверждением).
- **Срок хранения.** «Настройки → Данные → Хранить удалённое»: 7, 14, 30 (по умолчанию), 90 дней, 1 год или «Не
  очищать». Записи старше срока удаляются при запуске и раз в 6 часов. В разделе срок виден, там же ссылка
  «Изменить срок».
- Записи в корзине можно найти в обычном разделе оператором `is:trash`.

## Оформление

«Настройки → Оформление»:

- **Сцена** — «Авто», «Луг», «Осень», «Бумага», «Зима», «Классика». «Авто» выбирает по времени года (декабрь–февраль —
  «Зима», сентябрь–ноябрь — «Осень», иначе «Луг»). «Бумага» и «Классика» выбираются только вручную. «Классика» —
  гладкий вид без пикселей, как в прежних версиях.
- **Тема** — «Системная», «Светлая», «Тёмная» (у каждой сцены есть день и ночь). Переключатель темы есть и внизу
  боковой панели; тему и сцену можно сменить из палитры команд.
- **Шрифт текста** — «Округлый», «Строгий», «Мягкий пиксель», «Пиксельный». Работает только в пиксельных сценах;
  «Классика» всегда на шрифте Geist.
- **Живой фон** — включает и выключает фон графа (см. «Граф»).

## Все горячие клавиши

Список есть и в самом приложении: «Настройки → Горячие клавиши».

| Действие | Клавиши |
|---|---|
| Быстрая запись | `Ctrl+Shift+Space`, `Alt+N`, `N` |
| Вставить из буфера как новую запись | `Ctrl+V` вне полей ввода |
| Поиск в разделе | `/` |
| Палитра команд | `Ctrl+K` |
| Разделы | `1` Входящие, `2` База знаний, `3` Избранное, `4` Архив, `5` Граф |
| Закрыть панель или подробности | `Esc` |
| В списке | `J` `K` `Enter` `E` `A` `F` `X` `Del` |
| В корзине | `E` — восстановить, `Del` — удалить навсегда |
| В режиме «Разобрать» | `E` `A` `F` `S` `←` `→` `Del` |

На Mac вместо `Ctrl` — `⌘`. Клавиши работают и в русской раскладке. Глобальное сочетание для Windows
(по умолчанию `Ctrl+Shift+Space`) меняется в «Настройки → Быстрый захват»; если новое занято другой программой,
останется прежнее.

## Где лежат данные и как их не потерять

**Данные хранятся только на вашем устройстве** — в том браузере или приложении, где вы их добавили.
Синхронизации между устройствами нет: записи на компьютере и на телефоне — это два отдельных набора.
У установленного приложения и у веб-версии в браузере наборы тоже разные.

Что из этого следует:

- **Делайте резервные копии.** «Настройки → Данные → Экспорт резервной копии» сохраняет один файл JSON
  с записями (в том числе из корзины и с распознанным текстом), файлами, категориями, положениями записей на графе,
  сохранёнными поисками и настройками оформления.
- **Перенос на другое устройство** — экспорт на одном, «Импорт» на другом. При импорте выбирается режим:
  «Объединить» (добавить к имеющемуся) или «Заменить всё».
- **Что в копию не входит.** Ключ API и настройки ИИ и распознавания, прокси и загрузка заголовков, папки и
  расписание автокопий, настройки приёма от расширения. После переноса на другое устройство их нужно указать заново.
- **Очистка данных браузера удалит записи.** На iPhone Safari может сам стереть данные сайта, которым долго
  не пользовались, если он не добавлен на экран «Домой». Поэтому добавьте приложение на экран «Домой»
  и нажмите «Настройки → Данные → Защитить хранилище от очистки».

### Автоматические копии (Windows)

«Настройки → Копии и экспорт в папку»: «Папка для копий» (выбирается через «Выбрать…»), «Периодичность» («Выключено»,
«Каждый день», «Каждую неделю»), «Хранить копий» (от 1 до 100) и кнопка «Сделать копию сейчас». Копии лежат в
выбранной папке файлами `quickdrop-backup-ГГГГММДД-ЧЧММСС.json`; лишние старые копии удаляются сами, чужие файлы в
папке не трогаются. Копия делается, пока приложение запущено (проверка при старте и раз в час). Для настоящей
сохранности выбирайте папку на другом диске или в облачной папке.

### Экспорт в Markdown

Каждая запись — файл `.md` (с заголовком, категорией, тегами и датами в начале), вложения лежат в папке
`attachments`, связи и вики-ссылки превращаются в `[[ссылки]]`, как в Obsidian. Такую папку можно открыть любым
редактором Markdown.

- **Вся база в папку** (Windows): «Настройки → Копии и экспорт в папку → Папка для Markdown» → «Экспортировать в
  Markdown». Виден ход и кнопка «Отмена». Файлы с теми же именами перезаписываются, остальное в папке не трогается,
  записи из корзины не выгружаются.
- **Одна запись:** меню «Действия с записью» → «Скачать как Markdown» (текст, идея, код, ссылка; работает и в
  браузере).

## Ссылки и заголовки страниц

В версии для Windows заголовок и описание страницы подтягиваются сами через пару секунд после сохранения.

В веб-версии и на iPhone браузер не даёт читать чужие страницы, поэтому заголовок собирается из адреса
(например, «dexie.org — React»). Его можно поправить вручную в подробностях записи. Автозагрузку заголовков
можно выключить в «Настройки → Ссылки».

## ИИ-помощник (необязательно)

По умолчанию выключен, приложение полностью работает без него. Если включить, в подробностях записи
и в режиме «Разобрать» появится кнопка, которая предлагает заголовок, краткое описание и теги, а картинки и сканы
PDF можно будет превращать в текст (см. «Распознанный текст»).

Как включить: «Настройки → ИИ-помощник» → выбрать DeepSeek или OpenAI (или указать свой адрес) →
вставить свой API-ключ → включить «Включить ИИ-помощника» → «Проверить подключение».

Что важно знать:

- Ключ нужен свой, запросы оплачиваются по тарифу провайдера.
- При нажатии кнопки подсказки провайдеру уходит текст записи (заголовок, адрес и описание страницы ссылки, начало
  содержимого). Сами файлы при этом не отправляются; распознанный текст в подсказку не входит.
- При распознавании провайдеру уходит изображение (у PDF — первые 5 страниц картинками). Для этого нужна модель,
  которая принимает изображения: впишите её в поле «Модель для распознавания» (пусто — используется основная
  модель). Пресет DeepSeek изображения не принимает.
- Кнопка «Проверить распознавание» отправляет одну проверочную картинку с надписью «QuickDrop 2468»; ответ с этими
  цифрами означает, что распознавание работает.
- Ключ хранится только на этом устройстве и в резервную копию не попадает.

## Быстрый захват и расширение (Windows)

«Настройки → Быстрый захват»:

| Настройка | Что делает |
|---|---|
| Мини-окно быстрой записи | Глобальное сочетание открывает маленькое окно поверх программ (включено по умолчанию) |
| Глобальное сочетание | Что нажимать из любой программы |
| Сворачивать в трей при закрытии | Крестик прячет окно в трей, QuickDrop продолжает работать (по умолчанию выключено: крестик закрывает приложение) |
| Запускать вместе с системой | После входа в Windows QuickDrop стартует свёрнутым в трей (по умолчанию выключено) |
| Принимать записи от расширения | Включает приём от расширения Chrome (по умолчанию выключено) |

**Трей.** Значок QuickDrop рядом с часами: клик — открыть главное окно; меню «Открыть QuickDrop», «Быстрая запись»,
«Выход». Из трея сочетание и приём от расширения продолжают работать. **Один экземпляр:** повторный запуск не
создаёт второго окна, а поднимает уже работающее.

### Расширение для Chrome

Кнопка в панели браузера, контекстное меню («Сохранить страницу в QuickDrop», «Сохранить ссылку в QuickDrop»,
«Сохранить выделенное в QuickDrop») и `Alt+Shift+Q` отправляют страницу, ссылку или выделенный текст во «Входящие».
Расширение умеет только отправлять; читать записи оно не может. Работает в Chrome 116+ и других браузерах на Chromium.
Папка с расширением входит в установщик QuickDrop; её путь показан в «Настройки → Быстрый захват» с кнопками
«Показать папку» и «Копировать путь».

Установка:

1. Включите «Принимать записи от расширения» — появятся порт (по умолчанию 47821) и токен.
2. В Chrome откройте `chrome://extensions`, включите «Режим разработчика», нажмите «Загрузить распакованное
   расширение» и выберите папку расширения.
3. Откройте настройки расширения (значок QuickDrop → «Настройки»), вставьте порт и токен, нажмите «Сохранить» и
   «Проверить соединение»: должно появиться «Соединение есть».

После обновления QuickDrop нажмите «Обновить» на карточке расширения в `chrome://extensions`. Закрепите значок
расширения на панели браузера.

Приём слушает только этот компьютер и только пока включён, а без верного токена запросы отклоняются. Но расширение
не может проверить, кто отвечает на порту: пока QuickDrop закрыт, порт может занять другая программа и получить токен
и отправляемое. На компьютере, которым пользуются несколько человек, выберите нестандартный порт и не пользуйтесь
расширением, когда QuickDrop закрыт. «Удалить все данные» выключает приём и удаляет токен.

## Если что-то не так

| Ситуация | Что сделать |
|---|---|
| Клавиши `N`, `J`, `E` не срабатывают | Курсор стоит в поле ввода — нажмите `Esc` или кликните по пустому месту |
| `Ctrl+Shift+Space` не открывает окно из другой программы | Сочетание занято — смените его в «Настройки → Быстрый захват». В браузере глобальной клавиши нет |
| У ссылки нет заголовка | В веб-версии это ожидаемо — задайте заголовок вручную |
| Запись пропала из списка | Проверьте фильтры и поле поиска («Сбросить фильтры»), загляните в «Архив» и «Корзину» |
| Удалили по ошибке | Нажмите «Отменить» в уведомлении, пока оно не исчезло, или восстановите запись в разделе «Корзина» |
| «Категории … нет» в пустой выдаче | В запросе есть `cat:` с именем несуществующей категории (удалена или переименована) |
| Расширение пишет «QuickDrop не запущен или приём выключен» | Запустите QuickDrop и включите «Принимать записи от расширения»; проверьте порт и токен |
| Распознавание: «Модель … не принимает изображения» | Впишите модель со зрением в «Настройки → ИИ-помощник → Модель для распознавания» |
| Распознавание: «Неверный API-ключ» или модель не найдена | Проверьте ключ, адрес API и название модели в «Настройки → ИИ-помощник» |
| Автораспознавание остановилось | Прочитайте причину в сообщении; после исправления настроек оно продолжится само, ручной кнопкой работает всегда |
| «Текст не найден» после распознавания | На картинке нет читаемого текста или он слишком мелкий; можно нажать «Распознать заново» |
| На телефоне нет записей с компьютера | Синхронизации нет — перенесите через экспорт и импорт |
