# QuickDrop — инструкция пользователя

QuickDrop — одно место, куда можно быстро сбросить что угодно: ссылку, текст, фрагмент кода, идею, файл или
картинку. Раскладывать по папкам заранее не нужно. Всё новое попадает во «Входящие», а потом вы разбираете
записи: назначаете категорию и теги, связываете между собой и переносите в базу знаний.

## Главная схема работы

1. **Сбросить.** Нажали горячую клавишу, вставили или набрали — запись во «Входящих».
2. **Разобрать.** Когда есть время, проходите «Входящие»: нужное — в базу знаний, лишнее — в архив или удалить.
3. **Найти.** Поиск по содержимому, фильтры по типу, категории и тегам.

Запись всегда находится в одном из трёх состояний:

| Состояние | Что это |
|---|---|
| Входящие | Новое, ещё не разобранное |
| База знаний | Разобранное и оставленное насовсем |
| Архив | Убрано с глаз, но не удалено |

«Избранное» — это не отдельное состояние, а отметка-звезда: избранной может быть запись и из входящих,
и из базы знаний.

## Запуск

- **Windows.** Установите `QuickDrop_0.1.0_x64-setup.exe` и запускайте из меню «Пуск». Установщик не подписан,
  поэтому SmartScreen покажет предупреждение: «Подробнее» → «Выполнить в любом случае».
- **Браузер.** Откройте адрес, по которому размещена веб-версия.
- **iPhone.** Откройте веб-версию в Safari, затем «Поделиться» → «На экран „Домой“». Приложение появится
  отдельной иконкой и будет открываться без адресной строки.

При первом запуске в приложении лежат демонстрационные записи, чтобы было видно, как всё выглядит.
Убрать их можно в «Настройки → Данные → Удалить все данные».

## Как добавить запись

### Панель быстрого добавления

Открывается любым способом:

- `Ctrl+Shift+Space` (на Mac `⌘+Shift+Space`);
- `Alt+N`;
- `N`, если курсор не стоит в поле ввода;
- кнопка «Добавить» слева вверху (на телефоне — круглая кнопка внизу справа).

В установленной версии для Windows `Ctrl+Shift+Space` работает **из любой программы**: окно QuickDrop
поднимается, и панель сразу открыта.

Дальше вставьте или наберите содержимое и нажмите `Enter`. Больше ничего заполнять не обязательно.

| Действие | Клавиши |
|---|---|
| Сохранить | `Enter` для однострочного текста, `Ctrl+Enter` — всегда |
| Перенос строки | `Shift+Enter` |
| Сохранить и добавить ещё одну | `Ctrl+Shift+Enter` |
| Закрыть без сохранения | `Esc` |

Для кода и многострочного текста простой `Enter` переносит строку, сохранять нужно через `Ctrl+Enter`.
На телефоне `Enter` всегда переносит строку, сохранение — кнопкой «Сохранить».

Если закрыть панель с набранным текстом, он останется черновиком и вернётся при следующем открытии.

### Тип записи определяется сам

| Что ввели | Каким типом станет |
|---|---|
| Один адрес сайта | Ссылка |
| Фрагмент программы | Код (язык тоже подбирается) |
| Обычный текст | Текст |
| Файл | Файл или изображение |

Тип «Идея» автоматически не ставится — выберите его сами в ряду переключателей под полем. Там же можно
исправить тип, если он определился неверно.

### Необязательные поля

Под полем ввода есть заголовок, категория и теги. Ещё два переключателя:

- **Сразу в базу знаний** — запись минует «Входящие».
- **Звезда** — сразу отметить избранным.

### Другие способы

- **Вставка из буфера.** Нажмите `Ctrl+V`, когда курсор не стоит в поле ввода: панель откроется уже
  с содержимым буфера, будь то текст или скопированная картинка.
- **Перетаскивание.** Перетащите файлы в окно приложения.
- **Скрепка** в панели добавления — выбрать файлы с диска. Каждый файл становится отдельной записью.
- **Строка «Быстрая запись»** вверху «Входящих»: набрали, `Enter` — и запись сохранена без открытия панели.

Один файл может быть не больше 100 МБ.

## Разбор входящих

«Входящие» — главная страница. Счётчик рядом с названием показывает, сколько записей ждут разбора.

### Клавишами в списке

Работают, когда курсор не стоит в поле ввода. Текущая строка отмечена цветной полосой слева.

| Клавиша | Действие |
|---|---|
| `J` или `↓` | К следующей записи |
| `K` или `↑` | К предыдущей |
| `Enter` или `O` | Открыть подробности |
| `E` | В базу знаний |
| `A` | В архив |
| `F` | В избранное / убрать |
| `X` | Отметить запись для группового действия |
| `Ctrl+A` | Отметить все видимые |
| `Del` | Удалить |

После `E`, `A` и `Del` курсор сам переходит на следующую запись, так что входящие можно разобрать, не трогая мышь.

### Режим «Разобрать»

Кнопка «Разобрать» справа вверху открывает записи по одной, крупно. Под записью — категория и теги,
изменения сохраняются сразу.

| Клавиша | Действие |
|---|---|
| `E` или `Ctrl+Enter` | В базу знаний |
| `A` | В архив |
| `→` или `S` | Пропустить |
| `←` | Назад |
| `F` | Избранное |
| `Del` | Удалить |

В конце показывается сводка: сколько записей ушло в базу, в архив и сколько удалено.

### Групповые действия

Отметьте несколько записей галочками (или `X`, или `Shift`+клик для диапазона). Внизу появится панель:
в базу знаний, в архив, назначить категорию, добавить теги, удалить.

### Отмена

После переноса, архивации и удаления внизу на несколько секунд появляется уведомление с кнопкой «Отменить».
Удалённую запись можно вернуть только так — корзины нет.

## Подробности записи

Клик по записи или `Enter` открывает панель справа (на телефоне — на весь экран). В ней можно:

- **Править заголовок и содержимое** — кликните по тексту. Изменения сохраняются сами.
- **Назначить категорию и теги.** Новую категорию можно создать прямо из поля выбора.
- **Связать с другой записью** — кнопка «Связать…», затем найдите нужную запись. Связь двусторонняя:
  она видна в обеих записях, по ней можно перейти.
- **Для ссылки** — открыть, скопировать адрес, обновить данные страницы, добавить заметку.
- **Для файла и изображения** — посмотреть, скачать, добавить заметку. Картинка по клику открывается крупно.
- **Для кода** — сменить язык подсветки, скопировать.

Закрыть панель — `Esc`.

## Категории и теги

**Категория** у записи одна. Это крупное деление: «Работа», «Обучение», «Идеи». У каждой свой цвет.

**Тегов** может быть сколько угодно. Это мелкие метки: `#react`, `#встречи`. Теги пишутся строчными буквами,
пробел заменяется дефисом. При вводе появляются подсказки из уже существующих тегов.

Оба списка показаны в боковой панели слева: клик по категории или тегу открывает базу знаний с этим фильтром.

Управление — в «Настройки → Категории» и «Настройки → Теги»: переименование, цвет, порядок, удаление.
Если переименовать тег в уже существующий, они сольются. При удалении категории записи остаются,
но теряют категорию.

## Поиск

Поле поиска вверху. Перейти в него — `/`. Поиск идёт по заголовку, содержимому, адресу ссылки, тегам,
имени файла и названию категории. Он прощает опечатки и находит по началу слова.

Поиск фильтрует текущий раздел. Чтобы искать по всему сразу, откройте палитру команд — `Ctrl+K`.

### Операторы

Можно сочетать с обычным текстом, например: `индексы type:ссылка tag:базы-данных`.

| Оператор | Что находит |
|---|---|
| `tag:слово` или `#слово` | Записи с тегом |
| `type:ссылка` | Записи типа: `текст`, `ссылка`, `код`, `идея`, `файл`, `изображение` |
| `is:fav` | Избранное |
| `is:inbox`, `is:library`, `is:archive` | По состоянию |
| `is:untagged` | Без тегов |
| `has:file` | С файлом или изображением |
| `cat:работа` | В категории; имя с пробелами — в кавычках: `cat:"мои проекты"` |
| `"точная фраза"` | Фразу целиком |

### Фильтры

Над списком — строка фильтров: типы, категория, теги, «Без тегов и категории», период. Справа — сортировка
(новые, старые, недавно изменённые, по названию) и переключатель «список / сетка».

### Палитра команд

`Ctrl+K` открывает окно, из которого можно найти любую запись в любом разделе, перейти в раздел,
создать запись или сменить тему. Стрелки — выбрать, `Enter` — открыть, `Esc` — закрыть.

## Разделы

| Раздел | Клавиша | Что в нём |
|---|---|---|
| Входящие | `1` | Новое и неразобранное |
| База знаний | `2` | Всё разобранное |
| Избранное | `3` | Записи со звездой |
| Архив | `4` | Убранное; отсюда запись можно вернуть |
| Настройки | — | Оформление, категории, теги, данные |

## Все горячие клавиши

| Действие | Клавиши |
|---|---|
| Быстрое добавление | `Ctrl+Shift+Space`, `Alt+N`, `N` |
| Вставить из буфера как новую запись | `Ctrl+V` вне полей ввода |
| Поиск в разделе | `/` |
| Палитра команд | `Ctrl+K` |
| Разделы | `1`, `2`, `3`, `4` |
| Закрыть панель или подробности | `Esc` |
| В списке | `J` `K` `Enter` `E` `A` `F` `X` `Del` |

На Mac вместо `Ctrl` — `⌘`. Клавиши работают и в русской раскладке. Глобальное сочетание для Windows
можно сменить в «Настройки → Горячие клавиши»; если новое занято другой программой, останется прежнее.

## Где лежат данные и как их не потерять

**Данные хранятся только на вашем устройстве** — в том браузере или приложении, где вы их добавили.
Синхронизации между устройствами нет: записи на компьютере и на телефоне — это два отдельных набора.
У установленного приложения и у веб-версии в браузере наборы тоже разные.

Что из этого следует:

- **Делайте резервные копии.** «Настройки → Данные → Экспорт резервной копии» сохраняет один файл JSON
  со всеми записями, файлами, категориями и настройками.
- **Перенос на другое устройство** — экспорт на одном, «Импорт» на другом. При импорте выбирается режим:
  «Объединить» (добавить к имеющемуся) или «Заменить всё».
- **Очистка данных браузера удалит записи.** На iPhone Safari может сам стереть данные сайта, которым долго
  не пользовались, если он не добавлен на экран «Домой». Поэтому добавьте приложение на экран «Домой»
  и нажмите «Настройки → Данные → Защитить хранилище от очистки».

## Ссылки и заголовки страниц

В версии для Windows заголовок и описание страницы подтягиваются сами через пару секунд после сохранения.

В веб-версии и на iPhone браузер не даёт читать чужие страницы, поэтому заголовок собирается из адреса
(например, «dexie.org — React»). Его можно поправить вручную в подробностях записи. Автозагрузку заголовков
можно выключить в «Настройки → Ссылки».

## ИИ-помощник (необязательно)

По умолчанию выключен, приложение полностью работает без него. Если включить, в подробностях записи
и в режиме «Разобрать» появится кнопка, которая предлагает заголовок, краткое описание и теги.

Как включить: «Настройки → ИИ-помощник» → выбрать DeepSeek или OpenAI (или указать свой адрес) →
вставить свой API-ключ → «Проверить подключение».

Что важно знать:

- Ключ нужен свой, запросы оплачиваются по тарифу провайдера.
- При нажатии кнопки текст записи отправляется провайдеру. Сами файлы не отправляются.
- Ключ хранится только на этом устройстве и в резервную копию не попадает.

## Если что-то не так

| Ситуация | Что сделать |
|---|---|
| Клавиши `N`, `J`, `E` не срабатывают | Курсор стоит в поле ввода — нажмите `Esc` или кликните по пустому месту |
| `Ctrl+Shift+Space` не открывает окно из другой программы | Сочетание занято — смените его в «Настройки → Горячие клавиши». В браузере глобальной клавиши нет |
| У ссылки нет заголовка | В веб-версии это ожидаемо — задайте заголовок вручную |
| Запись пропала из списка | Проверьте фильтры и поле поиска (кнопка «Сбросить»), загляните в «Архив» |
| Удалили по ошибке | Нажмите «Отменить» в уведомлении, пока оно не исчезло |
| На телефоне нет записей с компьютера | Синхронизации нет — перенесите через экспорт и импорт |
