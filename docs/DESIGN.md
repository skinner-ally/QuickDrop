# Дизайн QuickDrop

Заменяет раздел «Дизайн» в `CLAUDE.md`. Нормативно для всех экранов. Точные значения токенов и CSS —
`src/styles/scenes.css`, `src/styles/pixel.css`, `src/styles/fonts.css` (спецификация: `.progress/spec-stage1.md`).
Образец вида — `mockup/` (кроме графа: в приложении граф без грядок, ноды — квадраты цвета категории).

## 1. Сцены, ночь, шрифт

- На `<html>` всегда ровно один класс сцены: `sc-meadow` (Луг) · `sc-autumn` (Осень) · `sc-paper` (Бумага) ·
  `sc-winter` (Зима) · `sc-classic` (Классика). У четырёх пиксельных сцен дополнительно класс `pixel`.
- Ночь — класс `.dark` (настройка `theme`: system / light / dark). У каждой сцены свои дневная и ночная палитры.
- Шрифт текста — класс `ft-round` (Nunito, по умолчанию) · `ft-plain` (Geist) · `ft-soft` (Handjet) · `ft-pixel` (Tiny5).
  Действует только в пиксельных сценах.
- Настройки: `scene` (`auto` — по календарю: дек–фев «Зима», сен–ноя «Осень», иначе «Луг»; «Бумага» и «Классика» —
  только вручную), `font`, `ambient` («Живой фон»). Читать через `useScene()` из `components/layout/ThemeProvider`.
- **«Классика»** — прежний вид без изменений: токены `:root`/`.dark` из `src/index.css`, Geist, lucide, скругления,
  мягкие тени. Любая правка обязана оставлять «Классику» такой, какая она есть.

## 2. Как писать экран, чтобы он был верен в обоих стилях

1. Базовые утилиты Tailwind без префикса описывают «Классику» и общую раскладку (flex, gap, отступы, размеры).
2. Цвета — только токенами (`bg-background`, `bg-card`, `text-muted-foreground`, `border-border`, `bg-brand` …):
   пиксельные сцены подменяют значения этих токенов, компонент перекрашивается сам.
3. Пиксельная «кожа» (рамка, скос, ступенчатые углы) — классами-примитивами `px-*`. В «Классике» они не делают
   ничего; в пиксельных сценах задают фон, рамку, тень и состояния и **сильнее любых утилит** (в т.ч. `pixel:`).
   Примитив нельзя перекрашивать утилитой — у него есть модификаторы и атрибуты состояния.
4. Отличия раскладки — вариантом `pixel:` (`pixel:p-3.5`, `pixel:gap-1.5`, `pixel:hidden`, `hidden pixel:flex`).
   Ночь внутри пиксельной сцены: `pixel:dark:…`.
5. Компоненты `src/components/ui/*` не переписываются: в пиксельных сценах их вид задают правила по `data-slot`
   в `pixel.css`. Допустимая правка в `ui/*` — только замена иконки lucide на `Icon`.
6. Запрещено в компонентах: цвета hex/oklch, `rounded-*` ради пиксельного вида, `text-[13px]` и другие
   произвольные размеры шрифта, прямой импорт `lucide-react`, условия `if (pixel)` ради цвета или рамки
   (условие в коде допустимо только для разной структуры разметки).
7. Проверка каждого экрана: «Классика» день/ночь + «Осень» день/ночь (основная пиксельная сцена) + беглый
   просмотр «Луга», «Бумаги», «Зимы»; ширина 1200 и 375 px.

## 3. Токены: что для чего

| Токен (утилита) | Пиксельные сцены | Назначение |
|---|---|---|
| `--wood-dark` (`pixel:bg-wood-dark`) | тёмное дерево | фон окна между панелями, все рамки 2px, обводка контролов |
| `--wood`, `--wood-hi`, `--wood-lo` | дерево | полосы рамки панели; больше нигде |
| `--background` = `--paper` | бумага | основная плоскость внутри панели, поля списка |
| `--card`, `--muted`, `--secondary`, `--accent`, `--surface` = `--paper-2` | бумага темнее | строка/карточка, поле ввода, обычная кнопка, чип, наведение |
| `--border`, `--input` = `--paper-line` | линия на бумаге | разделители, рамка чипа и вставок, нижний скос |
| `--foreground` = `--ink` | чернила | основной текст; текст категорий и тегов |
| `--muted-foreground` = `--ink-dim` | приглушённые чернила | вторичный текст, подсказки, плейсхолдеры (контраст ≥ 4.5 на `--paper-2`) |
| `--brand` (`bg-brand text-brand-foreground`), `--brand-hi/lo` | терракота | ТОЛЬКО: главное действие («Добавить», «Сохранить»), счётчик входящих, фокус (обводка), подсветка поиска `<mark>` |
| `--gold` (`text-gold`, `bg-gold text-gold-ink`) | золото | выделение: курсор J/K, выбранная нода, активный чип/кнопка-переключатель, избранное |
| `--leaf` / `--brand` / `--ink-faint` | — | статусы: в базе знаний / во входящих / в архиве (флажки, метки) |
| `--destructive` = `--danger` | красный | удаление и ошибки (текст и значок, не заливка) |
| `--primary` = `--ink` | — | «сильная» нейтральная кнопка, отмеченный чекбокс |
| `--shadow` | — | цвет жёсткой тени |
| `--cat-<цвет>`, `--cat-<цвет>-soft`, `--cat-none` | свои значения | цвет категории: квадрат-образец, полоса строки, нода графа; `-soft` — фон плашки |

Brand не используется как цвет текста на бумаге (контраст ~3:1) и не раскрашивает второстепенное.
Текст поверх цвета категории не пишется: название категории — чернилами рядом с квадратом `px-sw`.

## 4. Пиксельные правила

- Единица пикселя — 2px. Отступы и размеры в пиксельных сценах кратны 2px; рамки — 2px.
- Скруглений нет (в пиксельных сценах `border-radius` обнулён глобально). Углы панелей — ступенчатые.
- Градиентов, свечений, размытий и мягких теней в интерфейсе нет. `shadow-*` и `ring-*` в пиксельных сценах
  отключены глобально: обводка — `outline-*`, тень — только жёсткая смещённая (`px-shadow`, 4px 4px 0).
- Объём кнопок и полей — внутренний скос 2px (светлая грань сверху-слева, тёмная снизу-справа).
- Фокус — обводка 2px `--brand` с отступом 2px (ставится автоматически). Курсор списка и выделение — 2px `--gold`.

## 5. Примитивы `px-*`

| Класс | Когда |
|---|---|
| `px-panel` | закреплённая панель оболочки: рама из дерева + бумага, ступенчатые углы (боковая панель, верхняя, сцена, детали). Внутренний отступ 14px (`--px-pad`). Сама не прокручивается — прокрутка во внутреннем блоке; внутри нельзя держать `position: fixed` |
| `px-panel-thin` | вложенная панель: секция настроек, легенда. Отступ 10px |
| `px-pop` | всплывающая поверхность: меню, поповер, диалог, toast — тонкая рама снаружи + жёсткая тень, углы прямые |
| `px-btn` (+ `px-btn-brand`, `px-btn-ghost`) | кнопка вне `ui/button`. Включённое состояние: `aria-pressed="true"` или `data-on="true"` (золото) |
| `px-chip` | тег, выбор категории, фильтр. Активный: `data-on="true"` / `aria-pressed="true"` |
| `px-field` | поле ввода и поиск вне `ui/input` (класс на `input`/`textarea` или на обёртке) |
| `px-toggle` | самодельный переключатель (`role="switch"`, `aria-checked`); обычно — `ui/switch` |
| `px-row` | строка списка / карточка. Состояния: `data-cursor="true"`, `aria-current="true"`, `data-checked="true"` |
| `px-flag` + `px-flag-l` / `px-flag-r`, `data-flag="fav|inbox|library|archive"` | флажки по краям строки |
| `px-catbar` | полоса категории 4px сверху; цвет — `style={{ '--c': 'var(--cat-blue)' }}` |
| `px-nav` | пункт навигации, строка палитры и меню. Активный: `aria-current`, `data-on="true"`, `aria-selected="true"` |
| `px-sw` | квадрат-образец цвета категории (размер `size-2.5`, фон — inline `var(--cat-*)`) |
| `px-count` | счётчик входящих на brand |
| `px-well` | вставка внутри панели: содержимое записи, код, превью |
| `px-divider` | разделитель строк настроек (2px `--paper-line`) |
| `px-scrim` · `px-shadow` · `px-corners` · `px-sel` · `px-sheet` · `px-pop-in` | затемнение · жёсткая тень · ступенчатые углы · золотая обводка · панель-лист на телефоне (без среза углов) · появление `steps(3)` |

Кнопки, поля, переключатели, меню, диалоги, вкладки, подсказки и toast из `ui/*` стилизуются сами — добавлять
к ним `px-*` не нужно (исключение: явно задать вид кнопке с нестандартным фоном — `px-btn`, `px-btn-ghost`).

## 6. Шрифты

- `font-sans` → `--font-body` (текст), `font-heading` → `--font-head`. В пиксельных сценах заголовочный шрифт —
  Tiny5; им набираются только логотип и заголовки разделов (в т.ч. заголовок диалога). Весь остальной текст — `--font-body`.
- Размеры — только токенами: `text-2xs` (11) · `text-xs` (12) · `text-2sm` (13; 14 в пиксельных сценах) · `text-sm` (14) ·
  `text-md` (15) · `text-base` (16) · `text-lg` (18, заголовок записи) · `text-2xl` (24, заголовок раздела).
  `ft-soft` и `ft-pixel` переопределяют эти переменные (Handjet 17px, Tiny5 16/24px) — вёрстка не должна
  зависеть от точной высоты строки: никаких фиксированных высот под текст, только `min-h-*`.
- Насыщенность — `font-normal` / `font-medium` / `font-semibold`: шрифтовой класс сам подставляет веса
  (Nunito 600/700/800, Geist 450/550/650, Handjet 600/600/700, Tiny5 400). Заголовок раздела:
  `font-heading text-lg pixel:text-2xl` (вес в пиксельных сценах выставляется автоматически).
- Моноширинный — `font-mono` (код, адреса), не меняется.

## 7. Иконки

- Только `<Icon name="…" />` из `@/components/icons` (тип записи — `TypeIcon`). Список имён — `src/components/icons/names.ts`.
  В пиксельных сценах рисуется `PixelIcon` (SVG из квадратов), в «Классике» — lucide (`strokeWidth` 1.75).
- Размер — проп `size` (px). Пиксельный значок привязан к сетке (размер округляется вниз до кратного сетке):
  служебные 8×8 → 16 / 24 / 32 / 40 / 48 px, значки типа 10×10 → 20 / 30 / 40 / 50 / 60 px; классы `size-*` на
  пиксельный значок не действуют. Цвет — `text-*` (`currentColor`). (уточнено при сверке: ряд размеров приведён к
  `snapIconSize` из спецификации этапа 1; этап 3 использует 48 px в пустых состояниях.)
- Новый значок: имя в `names.ts`, lucide в `registry.ts`, карта пикселей в `pixel/*.ts` — всё три сразу.

## 8. Категории

- Цвет — `var(--cat-<color>)`, фон плашки — `var(--cat-<color>-soft)`, запись без категории — `var(--cat-none)`.
  В пиксельных сценах у переменных свои значения (палитра мокапа), день и ночь одинаковые.
- В интерфейсе слово «категории» (не «грядки»). На графе нода — квадрат, целиком залитый цветом категории.

## 9. Анимации

- 120–180 мс. В пиксельных сценах — ступенчатые: `steps(3)`/`steps(4)`; наведение и нажатие — мгновенно
  (нажатая кнопка сдвигается на 2px вниз). Масштабирование при появлении всплывающих окон отключено.
- `prefers-reduced-motion` уважается глобально (правило в `index.css`); свои анимации обязаны его не обходить.

## 10. Телефон (< 768px)

- Боковая панель — выезжающее меню; детали записи — лист на весь экран (`px-sheet`); «Добавить» — плавающая
  кнопка 56px с жёсткой тенью; учитывать `env(safe-area-inset-*)`.
- Зоны нажатия ≥ 36px; подсказки клавиш и действия по наведению скрыты. Вёрстка не должна ломаться;
  на настоящем устройстве не проверяется.

## 11. Живой фон

Лес, пруды, листопад, лучи, снег, бабочки и светлячки — отдельный слой canvas под и над графом (этап 6), только в
разделе «Граф». Не рисуется при выключенном `ambient`, скрытом окне, `prefers-reduced-motion` и в «Классике».
К панелям, спискам и диалогам фон отношения не имеет: их вид задают только токены и примитивы.
