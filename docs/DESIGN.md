# Дизайн QuickDrop

Заменяет раздел «Дизайн» в `CLAUDE.md`. Нормативно для всех экранов. Точные значения токенов и CSS —
`src/styles/scenes.css`, `src/styles/pixel.css`, `src/styles/fonts.css` (спецификация: `.progress/spec-stage1.md`).
Образец вида — `mockup/` (кроме графа: в приложении граф без грядок, ноды — квадраты цвета категории).

## 1. Сцены, ночь, шрифт

- На `<html>` всегда ровно один класс сцены: `sc-meadow` (Луг) · `sc-autumn` (Осень) · `sc-paper` (Бумага) ·
  `sc-winter` (Зима) · `sc-classic` (Классика). У четырёх пиксельных сцен дополнительно класс `pixel`.
- Ночь — класс `.dark` (настройка `theme`: system / light / dark). У каждой сцены свои дневная и ночная палитры.
- Шрифт текста — класс `ft-round` (Nunito, по умолчанию) · `ft-plain` (Geist) · `ft-soft` (Handjet) · `ft-pixel` (Tiny5).
  Действует только в пиксельных сценах.
- Настройки: `scene` (`auto` — по календарю: дек–фев «Зима», сен–ноя «Осень», иначе «Луг»; «Бумага» и «Классика» —
  только вручную), `font`, `ambient` («Живой фон»). Читать через `useScene()` из `components/layout/ThemeProvider`.
- **«Классика»** — прежний вид без изменений: токены `:root`/`.dark` из `src/index.css`, Geist, lucide, скругления,
  мягкие тени. Любая правка обязана оставлять «Классику» такой, какая она есть.

## 2. Как писать экран, чтобы он был верен в обоих стилях

1. Базовые утилиты Tailwind без префикса описывают «Классику» и общую раскладку (flex, gap, отступы, размеры).
2. Цвета — только токенами (`bg-background`, `bg-card`, `text-muted-foreground`, `border-border`, `bg-brand` …):
   пиксельные сцены подменяют значения этих токенов, компонент перекрашивается сам.
3. Пиксельная «кожа» (рамка, скос, ступенчатые углы) — классами-примитивами `px-*`. В «Классике» они не делают
   ничего; в пиксельных сценах задают фон, рамку, тень и состояния и **сильнее любых утилит** (в т.ч. `pixel:`).
   Примитив нельзя перекрашивать утилитой — у него есть модификаторы и атрибуты состояния.
4. Отличия раскладки — вариантом `pixel:` (`pixel:p-3.5`, `pixel:gap-1.5`, `pixel:hidden`, `hidden pixel:flex`).
   Ночь внутри пиксельной сцены: `pixel:dark:…`.
5. Компоненты `src/components/ui/*` не переписываются: в пиксельных сценах их вид задают правила по `data-slot`
   в `pixel.css`. Допустимая правка в `ui/*` — только замена иконки lucide на `Icon`.
6. Запрещено в компонентах: цвета hex/oklch, `rounded-*` ради пиксельного вида, `text-[13px]` и другие
   произвольные размеры шрифта, прямой импорт `lucide-react`, условия `if (pixel)` ради цвета или рамки
   (условие в коде допустимо только для разной структуры разметки).
   Модификатор важности `!` (`!p-0`, `pixel:!hidden`) запрещён: правила `pixel.css` лежат вне слоёв Tailwind, и `!`
   ломает порядок, на который рассчитаны примитивы. Нужен другой вид — вариант `pixel:` или новый атрибут состояния.
   Прокручиваемый или обрезающий блок (overflow auto/hidden/scroll) с фокусируемыми детьми получает внутренний запас ≥ 4px (`pixel:p-1 pixel:-m-1`):
   обводка фокуса (2px + отступ 2px) и курсора списка иначе обрезается краем блока.
7. Проверка каждого экрана: «Классика» день/ночь + «Осень» день/ночь (основная пиксельная сцена) + беглый
   просмотр «Луга», «Бумаги», «Зимы»; ширина 1200 и 375 px.

## 3. Токены: что для чего

| Токен (утилита) | Пиксельные сцены | Назначение |
|---|---|---|
| `--wood-dark` (`pixel:bg-wood-dark`) | тёмное дерево | фон окна между панелями, все рамки 2px, обводка контролов |
| `--wood`, `--wood-hi`, `--wood-lo` | дерево | полосы рамки панели; больше нигде |
| `--background` = `--paper` | бумага | основная плоскость внутри панели, поля списка |
| `--card`, `--muted`, `--secondary`, `--accent`, `--surface` = `--paper-2` | бумага темнее | строка/карточка, поле ввода, обычная кнопка, чип, наведение |
| `--border`, `--input` = `--paper-line` | линия на бумаге | разделители, рамка чипа и вставок, нижний скос |
| `--foreground` = `--ink` | чернила | основной текст; текст категорий и тегов |
| `--muted-foreground` = `--ink-dim` | приглушённые чернила | вторичный текст, подсказки, плейсхолдеры (контраст ≥ 4.5 на `--paper-2`) |
| `--brand` (`bg-brand text-brand-foreground`), `--brand-hi/lo` | терракота | ТОЛЬКО: главное действие («Добавить», «Сохранить»), счётчик входящих, фокус (обводка), подсветка поиска `<mark>` |
| `--gold` (`text-gold`, `bg-gold text-gold-ink`) | золото | выделение: курсор J/K, выбранная нода, активный чип/кнопка-переключатель, избранное (см. правило про золото ниже) |
| `--leaf` / `--brand` / `--ink-faint` | — | статусы: в базе знаний / во входящих / в архиве (флажки, метки) |
| `--destructive` = `--danger` | красный | удаление и ошибки (текст и значок, не заливка) |
| `--primary` = `--ink` | — | «сильная» нейтральная кнопка, отмеченный чекбокс |
| `--shadow` | — | цвет жёсткой тени |
| `--cat-<цвет>`, `--cat-<цвет>-soft`, `--cat-none` | свои значения | цвет категории: квадрат-образец, полоса строки, нода графа; `-soft` — фон плашки |
| `--ground`, `--graph-*` (`--graph-bg`, `-node-edge`, `-shadow`, `-inbox`, `-inbox-edge`, `-sel`, `-sel-edge`, `-hover`, `-label`, `-label-edge`, `-link`, `-link-alt`, `-link-edge`, `-link-hot`) | земля сцены (`--ground`) и цвета графа | только граф (§13): фон сцены, рамка, тень, метка, подпись (текст и контур), выделение и связи; читает `lib/graph/theme.ts`. В «Классике» — без рамок и теней, на фоне `--background` |

Brand не используется как цвет текста на бумаге (контраст ~3:1) и не раскрашивает второстепенное.
Текст поверх цвета категории не пишется: название категории — чернилами рядом с квадратом `px-sw`.

**Золото на бумаге.** Контраст золота с бумагой низкий, поэтому золото как единственный индикатор не используется.
Допустимо только: (а) заливка с тёмной рамкой `wood-dark` — плашка, включённая кнопка/чип/вкладка; (б) линия с тёмной
кромкой — курсор списка (`px-row[data-cursor]`) и `px-sel`: золото 2px плюс снаружи обводка 2px `wood-dark`
(вылет 4px). Золотой значок или текст `text-gold` прямо на бумаге — только вместе с таким обрамлением.
Значок внутри включённой кнопки/чипа/вкладки сам наследует цвет кнопки (правило `.px-icon { color: inherit }` в
`pixel.css`); рецепт `pixel:text-inherit` не нужен. Невалидное поле (`aria-invalid="true"` у `ui/input`, `textarea`,
`select`, `input-group`) получает рамку `--danger` автоматически.

## 4. Пиксельные правила

- Единица пикселя — 2px. Отступы и размеры в пиксельных сценах кратны 2px; рамки — 2px.
- Скруглений нет (в пиксельных сценах `border-radius` обнулён глобально). Углы панелей — ступенчатые.
- Градиентов, свечений, размытий и мягких теней в интерфейсе нет. `shadow-*` и `ring-*` в пиксельных сценах
  отключены глобально: обводка — `outline-*`, тень — только жёсткая смещённая (`px-shadow`, 4px 4px 0).
- Объём кнопок и полей — внутренний скос 2px (светлая грань сверху-слева, тёмная снизу-справа).
- Фокус — обводка 2px `--brand` с отступом 2px (ставится автоматически). Курсор списка и выделение — 2px `--gold`
  с внешней кромкой 2px `--wood-dark` (см. правило про золото).

## 5. Примитивы `px-*`

| Класс | Когда |
|---|---|
| `px-panel` | закреплённая панель оболочки: рама из дерева + бумага, ступенчатые углы (боковая панель, верхняя, сцена, детали). Внутренний отступ 14px (`--px-pad`). Сама не прокручивается — прокрутка во внутреннем блоке; внутри нельзя держать `position: fixed` |
| `px-panel-thin` | вложенная панель: секция настроек, легенда. Отступ 10px |
| `px-pop` | всплывающая поверхность: меню, поповер, диалог, toast — тонкая рама снаружи + жёсткая тень, углы прямые |
| `px-btn` (+ `px-btn-brand`, `px-btn-ghost`) | кнопка вне `ui/button`. Включённое состояние: `aria-pressed="true"` или `data-on="true"` (золото) |
| `px-fab` | плавающая кнопка «Добавить» (класс на `ui/button`): скос brand + жёсткая тень 4px; размер 56px задаёт разметка |
| `px-chip` | тег, выбор категории, фильтр. Активный: `data-on="true"` / `aria-pressed="true"` |
| `px-field` | поле ввода и поиск вне `ui/input` (класс на `input`/`textarea` или на обёртке) |
| `px-toggle` | самодельный переключатель (`role="switch"`, `aria-checked`); обычно — `ui/switch` |
| `px-row` | строка списка / карточка. Состояния: `data-cursor="true"`, `aria-current="true"`, `data-checked="true"` |
| `px-flag` + `px-flag-l` / `px-flag-r`, `data-flag="fav|inbox|library|archive|trash"` | флажки по краям строки (`trash` — запись в корзине, `--danger`) |
| `px-catbar` | полоса категории 4px сверху; цвет — `style={{ '--c': 'var(--cat-blue)' }}` |
| `px-nav` | пункт навигации, строка палитры и меню. Активный: `aria-current`, `data-on="true"`, `aria-selected="true"` |
| `px-sw` | квадрат-образец цвета категории (размер `size-2.5`, фон — inline `var(--cat-*)`) |
| `px-count` | счётчик входящих на brand |
| `px-well` | вставка внутри панели: содержимое записи, код, превью |
| `px-divider` | разделитель строк настроек (2px `--paper-line`) |
| `px-icon` | служебный класс самого `PixelIcon` (цвет наследуется, `animate-spin` ступенчатый); вручную не ставится |
| `px-scrim` · `px-shadow` · `px-corners` · `px-sel` · `px-sheet` · `px-pop-in` | затемнение · жёсткая тень · ступенчатые углы · золотая обводка с тёмной кромкой · панель-лист на телефоне (без среза углов) · появление `steps(3)` |
| `px-graph-stage` | сцена графа (`div[data-graph-stage]`): фон `--graph-bg` (земля сцены), рамка 2px `wood-dark`, у canvas `image-rendering: pixelated`; обводка фокуса — внутрь: золото 2px вплотную к рамке и кромка `wood-dark` 2px изнутри (слой `::after` поверх canvas) |
| `px-graph-label` (+ `data-plate="true"`) | подпись ноды графа поверх сцены: текст `--graph-label` с контуром 2px `--graph-label-edge` прямо на земле (Луг, Осень — светлый текст, тёмный контур; Бумага, Зима — наоборот); с `data-plate="true"` (выбранная нода и её соседи) — плашка бумаги с рамкой 2px |

Переменные отступа: `--px-pad` — внутренний отступ `px-panel` / `px-panel-thin` и диалога-панели (по умолчанию 14 / 10px);
`--px-sheet-pad` — отступ `px-sheet` на телефоне (по умолчанию 8px, к нему добавляется `env(safe-area-inset-*)`).
Задаются на элементе через `style` или утилиту `[--px-pad:…]`, а не `padding`.

`DialogContent` (`ui/dialog`) принимает `data-skin`: без атрибута — обычная всплывающая поверхность (`px-pop`);
`data-skin="panel"` — рама-панель со ступенчатыми углами (быстрая запись; палитра команд распознаётся сама по
вложенному `data-slot="command"`); `data-skin="none"` — без кожи (лайтбокс изображения остаётся тёмным).

Кнопки, поля, переключатели, меню, диалоги, вкладки, подсказки и toast из `ui/*` стилизуются сами — добавлять
к ним `px-*` не нужно (исключение: явно задать вид кнопке с нестандартным фоном — `px-btn`, `px-btn-ghost`).

## 6. Шрифты

- `font-sans` → `--font-body` (текст), `font-heading` → `--font-head`. В пиксельных сценах заголовочный шрифт —
  Tiny5; им набираются только логотип и заголовки разделов (в т.ч. заголовок диалога). Весь остальной текст — `--font-body`.
- Размеры — только токенами: `text-2xs` (11) · `text-xs` (12) · `text-2sm` (13; 14 в пиксельных сценах) · `text-sm` (14) ·
  `text-md` (15) · `text-base` (16) · `text-lg` (18, заголовок записи) · `text-2xl` (24, заголовок раздела).
  `ft-soft` и `ft-pixel` переопределяют эти переменные (Handjet 17px, Tiny5 16/24px) — вёрстка не должна
  зависеть от точной высоты строки: никаких фиксированных высот под текст, только `min-h-*`.
- Насыщенность — `font-normal` / `font-medium` / `font-semibold`: шрифтовой класс сам подставляет веса
  (Nunito 600/700/800, Geist 450/550/650, Handjet 600/600/700, Tiny5 400). Заголовок раздела:
  `font-heading text-lg pixel:text-2xl` (вес в пиксельных сценах выставляется автоматически).
- Моноширинный — `font-mono` (код, адреса), не меняется.

## 7. Иконки

- Только `<Icon name="…" />` из `@/components/icons` (тип записи — `TypeIcon`). Список имён — `src/components/icons/names.ts`.
  В пиксельных сценах рисуется `PixelIcon` (SVG из квадратов), в «Классике» — lucide (`strokeWidth` 1.75).
- Размер — проп `size` (px). Пиксельный значок привязан к сетке (размер округляется вниз до кратного сетке):
  служебные 8×8 → 16 / 24 / 32 / 40 / 48 px, значки типа 10×10 → 20 / 30 / 40 / 50 / 60 px; классы `size-*` на
  пиксельный значок не действуют. Цвет — `text-*` (`currentColor`). (уточнено при сверке: ряд размеров приведён к
  `snapIconSize` из спецификации этапа 1; этап 3 использует 48 px в пустых состояниях.)
- Проп `pixelSize` (у `Icon` и `TypeIcon`) — размер пиксельного значка, если он должен отличаться от `size`
  (`<Icon name="circle-check" size={24} pixelSize={48} />`: в «Классике» 24, в пиксельных сценах 48). Без него в
  пиксельных сценах берётся `size`.
- Новый значок: имя в `names.ts`, lucide в `registry.ts`, карта пикселей в `pixel/*.ts` — всё три сразу.

## 8. Категории

- Цвет — `var(--cat-<color>)`, фон плашки — `var(--cat-<color>-soft)`, запись без категории — `var(--cat-none)`.
  В пиксельных сценах у переменных свои значения (палитра мокапа), день и ночь одинаковые.
- В интерфейсе слово «категории» (не «грядки»). На графе нода — квадрат, целиком залитый цветом категории.

## 9. Анимации

- 120–180 мс. В пиксельных сценах — ступенчатые: `steps(3)`/`steps(4)`; наведение и нажатие — мгновенно
  (нажатая кнопка сдвигается на 2px вниз). Масштабирование при появлении всплывающих окон отключено.
- `prefers-reduced-motion` уважается глобально (правило в `index.css`); свои анимации обязаны его не обходить.

## 10. Телефон (< 768px)

- Боковая панель — выезжающее меню; детали записи — лист на весь экран (`px-sheet`); «Добавить» — плавающая
  кнопка 56px с жёсткой тенью; учитывать `env(safe-area-inset-*)`.
- Зоны нажатия ≥ 36px; подсказки клавиш и действия по наведению скрыты. Вёрстка не должна ломаться;
  на настоящем устройстве не проверяется.

## 11. Живой фон

Лес, пруды, листопад, лучи, снег, бабочки и светлячки на сцене графа (этап 6; спецификация —
`.progress/spec-stage6.md`). К панелям, спискам и диалогам фон отношения не имеет: их вид задают только токены и
примитивы. Код — `src/lib/ambient/`; хост один, `GraphCanvas`, новых canvas в DOM нет.

- **Слои** (снизу вверх): земля — CSS-фон сцены (`--graph-bg` = `--ground`) · `canvas[data-graph-ambient="back"]` —
  плитки (мелочь земли, пруды, лес), затем эффекты под нодами (листопад) · `canvas[data-graph-canvas]` — связи и ноды
  (фон их не трогает) · `canvas[data-graph-ambient="front"]` — лучи или снег, затем бабочки или светлячки · DOM-подписи.
  Порядок как в мокапе: лес → листопад → ноды → лучи → снег, бабочки, светлячки. Canvas фона прозрачные и землю не красят.
- **Режимы** (`ambientMode`, `scheduler.ts`). `off` — слоя нет, ровная земля: раздел не «Граф» или сцены нет в DOM,
  «Живой фон» выключен, «Классика». `static` — лес и пруды нарисованы, эффектов и таймеров нет: включён
  `prefers-reduced-motion` или окно скрыто. `animated` — всё. Тики эффектов — около 12 в секунду (83 мс); цепочка
  «таймер → запрос кадра → кадр хоста → следующий таймер», собственного `requestAnimationFrame` у фона нет: пока окно
  не рисуется, таймеры не взводятся, а при уходе из раздела «Граф» кадров нет вовсе.
- **Решётка устройства** (`lattice.ts`). Пиксель графики фона — целое число `u` пикселей устройства, поэтому спрайты
  резкие при любом `devicePixelRatio`, а плитки (≈512 px устройства, углы на целых пикселях) стыкуются без швов и
  дробного масштаба. Положения объектов берутся от мира, размер спрайта — от `u`; относительный размер спрайта
  `0.8–1.34` номинального. Номинальный арт-пиксель — 2 px мира. На мелком масштабе уровень графики `lod` 0/1/2
  (спрайты в целом, ½ и ¼): выбирается по числу пикселей устройства в номинальном арт-пикселе — от 0,75 `lod` 0, от 0,375 `lod` 1, ниже `lod` 2. Масштаб — ступени §13.
- **Смягчение к земле.** На обзоре цвета фона смешиваются с землёй: 100 % и крупнее — нет; 75 % — 12 %; 50 % — 25 %;
  25 % — 40 %; 12,5 % — 50 %. Фон бледнеет и не спорит с нодами. Мелочь земли и узор сетки есть только на `lod` 0.
- **Поляны.** Под нодами и вокруг них фон пустой — ровная `--ground`. Дерево, сосна, куст, камень скрыты, если центр
  ноды лежит в рамке поляны объекта (спрайт с запасом: дерево 74 px вбок, 140 вверх и 44 вниз от опоры; сосна 60/134/44;
  куст 60/72/44; камень и мелочь 54/62/44). Пруд скрыт целиком (вместе с камышами и кувшинками), если нода ближе
  `r·1.45 + 56` к его центру; мелочь земли не рисуется ближе 56 px к ноде. Поляна не зависит от масштаба. Перенос
  ноды меняет фон один раз — после броска; затронутые плитки сменяются растворением в 3 шага (≈250 мс), при
  неподвижном режиме — сразу. Смена только приглушения нод плитки не трогает. Поэтому контраст нод и подписей к земле
  (§13) остаётся тем же, что без фона.
- **Эффекты** рисуются малым растром (арт-пиксель экрана — `2·dpr` пикселей устройства, растр ограничен по площади),
  целочисленно увеличиваются и не имеют состояния: картинка — функция часов и камеры. Часы идут только пока фон
  анимируется, пауза в них не входит.

  | Сцена | День | Ночь |
  |---|---|---|
  | Луг | лучи; бабочки от 75 % | светлячки от 50 % |
  | Осень | листопад от 50 %; лучи | листопад от 50 % |
  | Зима | снег | снег |
  | Бумага | — | — |

  Листья на ноды не ложатся (рядом с нодой лежащий лист не рисуется, летящий бледнеет); бабочка над нодой —
  с альфой ×0,3; светлячок рядом с нодой не рисуется. Единственная сплошная заливка поверх нод — лучи: белый с
  альфой не больше `AMBIENT_OVERLAY_MAX` (0,2). Под ней кромки ноды, связи и выделения к земле дневных «Луга» и «Осени»
  остаются ≥ 3, подпись к контуру ≥ 4.5 во всех восьми вариантах — это проверяет `lib/ambient/contrast.test.ts`.
- **«Бумага»** — без леса и прудов: точечная сетка с шагом сетки графа (точка в центре клетки между нодами; пока клетка
  на экране не меньше 8 px), волокна бумаги и редкие кляксы. Эффектов нет. Поляны для узора не действуют.
- **Память и скорость.** Плитки — в кэше до 16 млн пикселей решётки (64 МБ), невидимые вытесняются; новые плитки
  в кадре рисуются в бюджет 10 мс, остальные — в следующих кадрах (`requestAmbientFrame`); вокруг экрана держится запас в
  одну плитку, чтобы сдвиг не показывал недорисованные ряды. Код фона (`lib/ambient/controller` с движком, спрайтами,
  эффектами и pixelfx, около 40 % чанка после минимизации) статически входит в ленивый чанк графа и грузится с ним и в «Классике»,
  и при выключенном «Живом фоне»: так решено осознанно — в этих режимах слой не создаётся, спрайты не строятся и
  ничего не рисуется, а отдельная динамическая подгрузка добавила бы гонку загрузки с уходом из раздела ради разбора
  локального файла в Tauri.
- **Графика только своя:** процедурные карты пикселей в коде (`lib/ambient/sprites/`), чужих спрайтов и изображений нет.
  Цвета фона заданы палитрой сцен в коде (земля = `--ground`, это проверяет тест); цвета нод, связей и подписей — только
  `--graph-*` и `--cat-*` (§13).
- **pixelfx** (MIT, https://www.spritefusion.com/pixel-art-vfx): ядро не переносится. В `src/lib/pixelfx/` лежит малая
  часть на TypeScript — хеш и случайность, смешение цвета, `trips`, листопад и лучи; условия лицензии — файл
  `src/lib/pixelfx/LICENSE` и полный текст в шапке `math.ts` (только для исходников: минимизатор шапки `/*!` срезает).
  В сборку уведомление попадает файлом `public/licenses/pixelfx-LICENSE.txt` (копия `LICENSE`, совпадение сверяет тест;
  в PWA — в precache и вне `navigateFallback`). Снег, светлячки и бабочки написаны с нуля (`lib/ambient/effects/`).
  См. также «Сторонний код» в `README.md`.
- Настройка: один переключатель «Живой фон» (настройки → «Оформление»), подпунктов нет; выключен — ровная земля,
  как до этапа 6, леса тоже нет.

## 12. Markdown

- Отрисованный текст — только `<MarkdownText>` (`components/markdown`): обёртка `div.qd-md` (`data-density="compact"` —
  заметки к ссылке и файлу). Правила — `src/styles/markdown.css`: база в `@layer components` («Классика»), пиксельные
  отличия под `.pixel` вне слоёв (рамки 2px `--paper-line`, отступы кратны 2px). Свои классы в разметке Markdown не
  ставить и `qd-md` утилитами не перекрашивать; размер шрифта и высоту строки всего блока можно задать утилитой на самом `MarkdownText` (`text-md`, `leading-relaxed`:
  пиксельное `line-height: inherit` лежит в слое и утилиту не перебивает). Отступ между детьми пункта, цитаты и ячейки — только
  у блочных (абзац, код, список, таблица), строчные вики-ссылки и картинки его не получают.
- Заголовки набраны шрифтом текста (`--font-body`), не `--font-head`; brand как цвет текста не используется.
- Картинки не загружаются никогда: картинка Markdown — ссылка `.qd-md-img` со значком `file-image`. Сырой HTML —
  текстом. Код — через `CodeView`, задачи — `ui/checkbox` (`.qd-md-check`), вики-ссылка — `.qd-md-wiki`
  (не найдена — `data-missing`, приглушённая).
- Переключатель «Просмотр / Исходник» — `ViewModeToggle` (`useUi.mdPreview`, один на всё приложение).

## 13. Граф

Раздел «Граф»: ноды и связи записей на сцене со сдвигом и масштабом (спецификация: `.progress/spec-stage5.md`).
Образец общего вида — `mockup/`, но без грядок: нода — квадрат, целиком залитый цветом категории.

- **Слои сцены** (`div[data-graph-stage]`, `role="application"`, снизу вверх, все `absolute inset-0`):
  `canvas[data-graph-ambient="back"]` — живой фон под нодами (плитки леса и прудов, листопад; §11) ·
  `canvas[data-graph-canvas]` — связи и ноды · `canvas[data-graph-ambient="front"]` — фон поверх нод (лучи, снег,
  бабочки, светлячки) · `div[data-graph-overlay]` — DOM: подписи, подсказка ноды, меню, ручка связи. Оба canvas
  фона прозрачны; землю даёт CSS сцены, а ноды и подписи лежат на «полянах» — ровной земле без рисунка. Панель инструментов и первая подсказка — соседний слой поверх сцены (вне `role="application"`,
  повторяет внутренний край рамки). Интерактивный DOM помечается `data-graph-ui`: жесты и колесо внутри него сцена
  игнорирует; клавиши графа внутри него не работают, кроме панели инструментов (`role="toolbar"`).
- **Ноды и связи рисует canvas**, а не DOM. Цвета берутся только из переменных `--graph-*` и `--cat-*` через
  `readGraphTheme` (`lib/graph/theme.ts`; пробник `var()` + `getComputedStyle`) и перечитываются при смене сцены, ночи
  и шрифта (`subscribeGraphTheme`). **В компонентах графа цветов нет**: ни hex/oklch, ни утилит цвета ради нод.
- **Сцена и подпись.** Контейнер сцены — `px-graph-stage` (земля `--ground` через `--graph-bg`, рамка 2px `wood-dark`;
  в «Классике» — фон `--background`). Подпись ноды — `px-graph-label`: текст `--graph-label` с контуром
  `--graph-label-edge` прямо на земле (контраст текста к контуру ≥ 4.5:1 во всех сценах; на «Бумаге» и «Зиме» тёмный
  текст со светлым контуром); выбранная нода и её соседи — `data-plate="true"` (бумажная плашка с рамкой). Подпись не
  рисуется на canvas и не закрывает другие ноды и подписи; ниже 100 % масштаба подписей нет, только подсказка при наведении.
- **Нода** — квадрат 16 px мира на сетке 32 px. В пиксельных сценах рамка 2px `--graph-node-edge` и жёсткая тень
  `--graph-shadow`; ниже 50 % масштаба рамки и тени нет — вместо рамки тёмный контур 1 px снаружи квадрата (если между
  нодами остаётся ≥ 3 px земли; на 12,5 % при dpr 1 — голая заливка). В «Классике» (`--graph-node-edge` и
  `--graph-shadow` прозрачны) только заливка. Запись из «Входящих» — квадратная метка в правом верхнем углу
  (`--graph-inbox` с кромкой `--graph-inbox-edge`), от 50 % масштаба.
- **Выделение** — правило про золото (§3): в пиксельных сценах золото `--graph-sel` с тёмной кромкой `--graph-sel-edge`,
  в «Классике» — brand без кромки. Соседи выбранной — золото вплотную, наведение и курсор клавиатуры — `--graph-hover`
  вплотную; у всех снаружи та же тёмная кромка `--graph-sel-edge`. Золото без тёмной кромки на земле не используется.
- **Связи** в пиксельных сценах — линия Брезенхэма толщиной в «пиксель» сцены: у каждой связи сначала тёмная кромка
  `--graph-link-edge` (3×3 «пикселя» вокруг шага), затем сердцевина — чередование `--graph-link` и `--graph-link-alt`;
  между зонами — пунктир (в разрывах нет и кромки), «горячие» (у выбранной, наведённой ноды и под курсором) — золото
  `--graph-link-hot` с той же кромкой. Без кромки светлые цвета верёвки на дневной земле не видны. При u = 1 (одна
  точка экрана на «пиксель» связи, это примерно ниже 50 % при dpr 1) у обычных и приглушённых связей кромки нет
  (второй проход по всем связям вдвое замедлял кадр), а сердцевина рисуется цветом `--graph-link-edge` с альфой
  `linkZoomAlpha`; у горячих связей кромка остаётся. В «Классике» — обычные тонкие линии.
- **Ручка связи** — кнопка 20 px у правого нижнего угла выбранной ноды снаружи (заходит на угол не более чем на 4 px;
  у нижнего и правого краёв сцены уходит на другой угол). Показывается от масштаба 100 %, только в окне от 1100 px
  (боковая панель деталей) и не на касании; пальцем связь делается удержанием записи и пунктом «Связать с…».
- **Выбор ноды** одиночным кликом мышью откладывается на время двойного клика (500 мс), если выбор меняет то, что
  под указателем: открывает модальный лист деталей или боковую панель в её полосе у правого края окна. Двойной клик
  центрирует на ноде со 100 %. Нода второго клика берётся из памяти первого, если сцена с тех пор сдвинулась.
- **Клавиатура.** Tab обходит соседей выбранной ноды один раз и не ловит фокус; Enter при уже открытой записи
  переводит фокус в панель деталей. Перенос ноды и выбор связи для удаления доступны только указателем (связь
  снимается с клавиатуры через панель деталей).
- **Ноды поверх связей**, а альфа обычных и приглушённых связей убывает с масштабом (`linkZoomAlpha`, `lib/graph/draw.ts`):
  1 от 100 %, ≈0.78 на 50 %, ≈0.57 на 25 %, 0.35 на 12,5 %. Иначе на обзорном масштабе тысячи связей сливаются в
  штриховку. Горячие связи не ослабляются.
- **Читаемость на земле** держится тёмной кромкой (связи, рамки) или контрастом цвета; значения `--graph-*` в
  `scenes.css` проверяет тест (`lib/graph/theme.test.ts`) для всех восьми вариантов сцен (день и ночь).
- **Приглушение:** нода или связь, не прошедшие отбор, — альфа 0.2 (`GRAPH_ALPHA_DIM`); архивная нода — 0.45
  (`GRAPH_ALPHA_ARCHIVED`). Альфа относится к ноде целиком: рамка, тень, заливка и метка полупрозрачной ноды не
  накладываются друг на друга. Отбор всегда приглушает, а не убирает: место ноды от него не зависит.
- **Масштаб — только ступенями** `0.125, 0.25, 0.5, 0.75, 1, 1.5, 2`; промежуточных значений камера не принимает.
  Координаты и размеры при рисовании — целые пиксели устройства (шаг сетки × ступень × `devicePixelRatio` целый), без
  сглаживания: `imageSmoothingEnabled = false`.
- **Живой фон** (этап 6, подробно — §11) подключается через контракт `lib/graph/ambient.ts` (`setAmbientLayer`, слой
  ставит `useAmbient` в `GraphView`); в «Классике» его нет. Хост по запросу фона (`requestAmbientFrame`, причина
  `'frame'`) перерисовывает только фон, граф — при смене слоя (`'layer'`) и когда изменился сам граф. Читаемость нод и
  подписей на лесу держат поляны (земля под нодами ровная) и тест `lib/ambient/contrast.test.ts` (лучи — единственная
  заливка поверх нод); «Живой фон» выключается одним переключателем в настройках.
- Остальной DOM графа собирается из существующих примитивов: всплывающие — `px-pop`, кнопки — `ui/button` и `px-btn`,
  чип масштаба — `px-chip`, образец цвета — `px-sw`. Новых примитивов нет.
- Панель отбора графа — `FilterBar mode="graph"`: те же фильтры, без сортировки и вида списка.
