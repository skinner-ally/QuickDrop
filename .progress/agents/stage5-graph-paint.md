# stage5-graph-paint

Задача: пакет «graph-paint» этапа 5 (волна 1) — `src/lib/graph/draw.ts` + `draw.test.ts` по `.progress/spec-stage5.md` §4.1.
Статус: готово

## Результат

`src/lib/graph/draw.ts` — экспорты по таблице §4.0: `LinkBuffer`, `linkUnit`, `drawLinksPixel`, `drawLinksClassic`,
`drawNodes`. Импортирует только волну 0 (`geometry`, `types`, `graphLayout.GRAPH_NODE_SIZE`).

- `drawLinksPixel`: решётка блоков u×u с углом `(ox mod u, oy mod u)`; Брезенхэм по номерам блоков; номер шага `s`
  считается от начала связи и не зависит от отсечения (поперечное смещение шага — `floor((2·s·minor + major) / (2·major))`,
  поэтому обход начинается сразу с видимого шага). Отсечение Лианга — Барски в номерах блоков с запасом 1.5 блока.
  Чередование `(s >> 1) & 1`, пунктир `cross` — `s % 8 ≥ 5`; приглушённые — альфа × 0.2 в байте цвета (один раз на
  вызов); горячие (у выбранной / наведённой / под курсором ноды, `hotLink`, `tempLink`) — сначала кромки всех горячих
  3×3 блока, затем сердцевины; прозрачная кромка не пишется. Запись построчно с отсечением по границам буфера.
- `drawLinksClassic`: три прохода (приглушённые 0.2 / обычные / горячие ×2), в каждом один `beginPath`…`stroke`, пустой
  проход пропускается; линии обрезаются по экрану; в конце `globalAlpha = 1`.
- `drawNodes`: отсечение `queryBounds(visibleBounds(v, 32))`; проходы тень → рамка → заливка → метка «Входящие»;
  `fillStyle` и `globalAlpha` меняются только при смене значения; затем клетка броска, нода в точке указателя, рамки
  соседей, наведённой и курсора, выбранной (золото с зазором + кромка) и цели протяжки; в конце `globalAlpha = 1`.

Тесты `draw.test.ts` — 33, подставной контекст: целые аргументы `fillRect` (dpr 1…2 × все ступени, обе темы), отсечение
и граница, пиксельная тема и «Классика», 0.25 и 0.5, альфа, выделение, перетаскивание, цель протяжки, связи в буфере
(диагональ и крутая — непрерывные цепочки u×u, привязка решётки к миру, пунктир, приглушение, горячая, порядок, временная,
вне экрана, длинная, границы буфера без переноса строк), «Классика» (по stroke на проход), нагрузка.
Нагрузка: 2000 нод + 3000 связей, 0.125, 1600×1000 — ~5.7 мс после одного прогрева (без прогрева ~11 мс), предел 60.

`npm run typecheck` и `npm test` (55 файлов, 1770 тестов) — зелёные.

## Решения, не прописанные в спецификации

- Рамки выделения ноды, которую тянут, рисуются в точке указателя; связи этой ноды остаются на прежнем месте.
- Нода в точке указателя рисуется с альфой 1 (призрак на месте — min(своя альфа, 0.3)).
- Протягиваемая связь идёт к точке мира и при `targetId` (как в §4.1), считается в возвращаемом числе связей.
- Пороги рамки, тени и метки — по `k = zoom · dpr` (как в §4.1): при dpr 2 метка видна уже с 25 %, Р4 говорит «от 50 %».
- Рамка соседей выбранной в пиксельных сценах — золото без внешней тёмной кромки (как в §4.1); изнутри к ней
  прилегает тёмная рамка самой ноды. Если приёмка сочтёт это нарушением правила про золото — добавить кромку `selEdge`.
