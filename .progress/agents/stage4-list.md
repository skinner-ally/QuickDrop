# stage4-list

Задача: этап 4, волна 1, пакет `list` (`.progress/spec-stage4.md` §5.2, §5.2a; Р7, Р8, Р9, Р11, Р15; §6).
Списки и раздел «Корзина»: `ItemVariant` += `'trash'`, запись в корзине по `item.deletedAt` (приглушённый заголовок,
«удалено … · ещё N дн.», флажок trash, быстрые действия «Восстановить» / «Удалить навсегда»), `itemActionList` для
корзины и «Скачать как Markdown», `BulkBar` с `trashed`, `ItemList` (inSection с корзиной, снимок с корзиной, клавиши
E/A/F/Del, `TrashDaysContext`, разделители по дням через `groupByDay`), сниппет и превью без разметки, долг
`text-[0.8rem]` в `BulkBar`, `TrashView` и подключение в `AppShell`.

Статус: готово

Порт dev-сервера: 5184 (остановлен, порт свободен).

## Результат
- `trashContext.ts` (нов.): `TrashDaysContext = createContext<number>(DEFAULT_SETTINGS.trashDays)`.
- `ItemCard.tsx`: `ItemVariant` += `'trash'`; `sameItem` сравнивает `deletedAt`. У записи с `deletedAt` (строка и
  карточка сетки): заголовок `text-muted-foreground`; `TrashMeta` вместо времени создания — «удалено <formatRelative>»
  и `trashLeftLabel` (≤ 3 дн. — `text-destructive`), `title` «Удалено: <formatDateTime>»; срок — из `TrashDaysContext`;
  К — одной строкой через « · », П — в колонке метаданных строки двумя строками (`stacked`), в мобильной строке и в
  карточке — одной. Правый флажок `data-flag="trash"`, звезда `StarMark` не рисуется, левый флажок как был.
  `QuickActions`: «Восстановить» (`undo`) → `actRestoreFromTrash`, «Удалить навсегда» (`trash`, destructive) →
  `actPurgeAsk`. Мобильная строка метаданных получила `title` с точной датой. `snippetOf` (ветка по умолчанию):
  пропускается строка `derivedTitleLine().index`, при `null` — сниппет из всего content. `CardPreview`:
  `stripMarkdown(content.slice(0, 600)).slice(0, 400)`.
- `ItemMenu.tsx` `itemActionList`: запись в корзине — «Открыть ссылку» (ссылка), «Копировать», «Скачать» (файл),
  «Восстановить» (`undo`, E), «Удалить навсегда» (`trash`, destructive, Del). Вне корзины — прежний список + «Скачать как

- `ItemList.tsx`: `wantTrashed = variant === 'trash' || parseQuery(query).filter.trashed`; `inSection(item, variant,
  wantTrashed)`; три поиска открытой записи — `getItemsWithTrashSnapshot()`; клавиши: E — корзина →
  `actRestoreFromTrash`, вне — как раньше; A, F — только вне корзины (иначе поглощаются); Del/Backspace — корзина →
  `actPurgeAsk`, вне → `actDelete`. Провайдер `TrashDaysContext` (`useSettings()?.trashDays ?? DEFAULT`),

  слов поиска и (`variant === 'trash'` или сортировка не «по названию»); отметка: корзина — `deletedAt ?? createdAt`,
  «изменённые» — `updatedAt`, иначе `createdAt`; `now` = `useDayKey()`; ключ заголовка — из `DayEntry`.
- `TrashView.tsx` (нов.): `useVisibleItems({ trashed: true })`, без слов — порядок по `deletedAt` (новые сверху);
  разметка как `ItemsView`; шапка «Корзина», «N из M», подсказка клавиш, пояснение срока / «Автоочистка выключена»,
  кнопка-ссылка «Изменить срок» → `setView('settings')`, «Очистить корзину» (`outline sm`, `trash`, выключена при

  пуста» (со сроком / «пока вы не очистите корзину») и «Ничего не найдено» + «Сбросить поиск».
