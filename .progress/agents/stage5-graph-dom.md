# stage5-graph-dom

- Задача: пакет «graph-dom» этапа 5 (волна 1) — DOM-слой поверх canvas графа: `GraphOverlay`, `GraphLabels`,
  `GraphTooltip`, `GraphNodeMenu`, `GraphCategoryPicker`, `GraphLinkTools`, `GraphA11y`. Спецификация —
  `.progress/spec-stage5.md` §4.3 (+ §0 Р6, Р11, Р12, Р17, Р18, §2.6, §3.7).
- Статус: готово (без проверки в браузере — раздел открывается после волны 2)

## Результат

- `GraphOverlay.tsx`: `GraphOverlay(props: GraphOverlayProps)` и `GraphOverlayProps { scene, items: ReadonlyMap<string, Item>,
  categories: readonly Category[] }` строго по §4.0; корень `div[data-graph-overlay].pointer-events-none.absolute.inset-0.overflow-hidden`.
- `GraphLabels.tsx`: набор подписей — `pickLabels(scene, visibleBounds(запас в пол-экрана), zoom, [selectedId, до 24 соседей])`
  в `useMemo` (масштаб, размер, сцена, выбор — сразу; сдвиг — через счётчик с задержкой 120 мс). Сдвиг — только
  `style.transform` контейнера: из `useGraph.subscribe` (только при смене `camera`/`viewSize`) и из `useLayoutEffect` на
  каждом коммите; камера x, y в React не подписывается (подписка на `zoom`, ширину, высоту). Элемент —
  `span.px-graph-label[data-plate]`, `aria-hidden`, классы «Классики» по спецификации (+ у плашки `bg-popover`, кольцо `border`).
- `GraphTooltip.tsx`: подсказка через 250 мс наведения, скрыта при `drag`, меню, выборе категории; заголовок, «тип · статус»,
  категория с `px-sw`, до 4 тегов, «Связей: N» (по сцене); справа-снизу от ноды, у края сцены — слева/выше. Вдобавок файл
  хранит общие помощники пакета (в отдельный файл нельзя — список файлов фиксирован): `STATUS_LABEL`, `overlayViewport`,
  `focusGraphStage`, `placeBox` (зажим коробки в сцену с запасом 8 px под раму и тень `px-pop`), `useMeasuredSize`.
- `GraphNodeMenu.tsx`: `DropdownMenu` с управляемым `open`, якорь — `span` 1×1 px в `(menu.x, menu.y)` (`DropdownMenuTrigger`
  `nativeButton={false}`); пункты «Открыть», «Категория…» (E), «Связать с…» (L), разделитель и `itemActionList(item)`.
  Корень смонтирован всегда (иначе закрытие не вернёт фокус), последние запись и точка хранятся на время анимации закрытия.
  `finalFocus`: после «Категория…» — не трогает фокус (его берёт список), иначе — на сцену.
- `GraphCategoryPicker.tsx`: список у ноды (ниже, у края — выше), `role="listbox"`, `aria-label="Категория записи"`,
  строки `role="option"` с `aria-selected`: «0 Без категории», затем категории; цифры `1–9` у первых девяти (`Kbd`, на касании
  скрыты). Клавиши внутри — `preventDefault` + `stopPropagation` (цифры 0–9 с основной и цифровой клавиатуры, ↑/↓, Tab по
  кругу, Home/End, Enter/Пробел, Esc); любые клавиши без Ctrl/⌘/Alt до горячих клавиш приложения не доходят. Выбор →
  `actSetCategory`, `openPicker(null)`, фокус на сцену. Клик вне закрывает; прокрутка `max-h-64 overflow-y-auto p-1`.
- `GraphLinkTools.tsx`: ручка (`button[data-graph-handle]`, 20×20, пиксельные 24, на касании 36, только у выбранной ноды,
  `zoom ≥ 0.5`, без жеста; `aria-pressed` в режиме связи; у нижнего края — над нодой), строка режима связи (`role="status"`,
  «Связать «…» — выберите вторую запись» + «Отмена», заголовок усекается отдельно), плашка выбранной связи («А — Б» +
  «Убрать связь» → `actUnlinkItems`, клик вне закрывает; если конец связи пропал из сцены — выбор снимается).
- `GraphA11y.tsx`: `p#graph-a11y-help.sr-only` и `div.sr-only[aria-live="polite"]` с описанием ноды `cursorId ?? selectedId`;
  в режиме связи — «Выберите запись для связи. …». Экспортирует `GRAPH_A11Y_HELP_ID`.
- Все интерактивные элементы (кроме ручки) — `pointer-events-auto` + `data-graph-ui`; подсказка — `pointer-events-none`.
- Зоны нажатия на телефоне: ручка, «Отмена», «Убрать связь» — 36 px (`pointer-coarse:`), строки выбора категории — `min-h-9`.

## Проверено

- `npm run typecheck` чист; `npm test` — 54 файла / 1737 тестов зелёные.
- Временный SSR-прогон (`renderToString`, затем файл удалён; стор подменён моком хука): `GraphOverlay` рендерится без
  ошибок при выбранной ноде (две подписи-плашки, ручка с `data-graph-handle`, строка диктора «Запись a. Текст. Категория:
  Кат. Входящие. Связей: 1.»), при режиме связи, выбранной связи и открытом выборе категории (строка текущей категории
  `aria-selected="true"`), при открытом `menu` в сторе.

## Отклонения от спецификации

- Подсказка клавиши `E` в `GraphNodeMenu` у пунктов из `itemActionList` («В базу знаний», «Восстановить») скрыта: в графе
  `E` — категория (Р12), подсказка была бы неверной. Остальные подсказки (A, F, Del) показываются.
- Общие помощники (`placeBox`, `useMeasuredSize`, `focusGraphStage`, `STATUS_LABEL`, `overlayViewport`) лежат в
  `GraphTooltip.tsx`, а не в отдельном файле: список файлов пакета закрыт. Циклических импортов нет (`GraphOverlay` импортируют
  соседи только как тип).
- Выбор категории в «Классике» и пиксельных сценах рисуется одной разметкой: `px-pop` + классы «Классики»; строки —
  `px-nav` (в «Классике» без действия), у текущей категории справа значок `check`.
- Плашка выбранной ноды в «Классике» дополнена `bg-popover` и тонким кольцом — спецификация описывает только `data-plate`.

## Нужно в pixel.css

Ничего не потребовалось: вид собран из `px-graph-label`, `px-pop`, `px-btn`, `px-nav`, `px-sw`.

## Не проверено

- Вид и поведение в браузере: раздел «Граф» откроется после волны 2 (`graph-screen`). Не проверены: фактическое положение
  и обрезка у краёв сцены (`placeBox` по измеренным размерам), цвета и рамки `px-pop`/`px-nav` в «Осени» и «Классике»,
  меню Base UI с якорем-`span` и возврат фокуса (`finalFocus`), клик вне для списка категорий и плашки, поведение на
  390 px, отсутствие перерисовки React при сдвиге (по коду: подписка на `zoom`/размер, а не на камеру).
- Сценарии §4.3 целиком — за `graph-screen`.
