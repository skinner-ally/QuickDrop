# stage4-capture-palette

Статус: готово

Задача: QuickCapture — предупреждение о дубле ссылки; CommandPalette — корзина, поиски (spec-stage4 §5.5).

Результат:
- QuickCapture: DraftWithSource убран; строка «Такая ссылка уже есть» (debounce 300 мс, passive только при shownUrl === linkUrl); при сохранении синхронная проверка по снимку, остановка, role=alert, фокус на «Открыть», saving сброшен; «Открыть» / «Всё равно добавить».
- CommandPalette: openItemInSection, «Перейти: Корзина», «Очистить корзину» (trashCount > 0), «Сохранить текущий поиск» (isNarrowed), группа «Поиски», зависимости useMemo.

Файлы: src/components/capture/QuickCapture.tsx, src/components/palette/CommandPalette.tsx

Запросы CSS: нет.

Проверено: typecheck, npm test (1377) зелёные; в браузере (Осень): строка не появляется до 300 мс, Enter останавливает сохранение, alert + фокус на «Открыть», «Всё равно добавить» создаёт вторую запись; пункт «Перейти: Корзина» в палитре.

Не проверено: Классика, ночь, 390px, визуально (скриншоты не снимались); «Открыть» из архива/приписка «(в архиве)»; Ctrl+Enter; «Очистить корзину», «Сохранить текущий поиск», группа «Поиски» в браузере; смена раздела #/trash по клику.
