## Что проверено по коду и по `node_modules`

- `react-markdown` 10.1.0, `remark-gfm` 4.0.1 — одноразовым скриптом (в репозитории не оставлен):
  компонент `li` получает `node.position.start.offset` на маркере пункта (вложенные списки, цитата); у задачи класс
  `task-list-item`; `- [ ]` без текста и пункты в коде задачами не считаются; сырой HTML без `skipHtml` выводится
  текстом; `javascript:` обнуляется; одиночный перевод строки остаётся `\n` в текстовом узле; `[[x\|y]]` в ячейке
  таблицы приходит как `[[x|y]]`; свой узел `link` с адресом `qd-wiki:…` доходит до компонента `a` при своём
  `urlTransform`; `[[a *b* c]]` разбивается выделением (ограничение, Р4).
- Vitest берёт только `src/**/*.test.ts` в окружении node: тесты разбора Markdown — через `react-dom/server`.
- В `ItemDetail` точные «Создано» и «Изменено» уже есть; значок плавающей кнопки, `data-skin`, `within` в `LinkPicker`,
  `positions`/`searches` в отчёте импорта — уже сделаны.
