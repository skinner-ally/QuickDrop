# fix-review5-graph-dom

Задача: исправления ревью этапа 5, группа «graph-dom» (C5, C11 = C27, C28, M4, M15, M16, M20, замечание приёмки про
счётчик в GraphHeader; из прочих minor в моих файлах — M18 п.3 и M19 про двойное объявление).

Статус: готово (typecheck и все 1860 тестов проходят; браузер не запускался)

## Исправлено
- C5: ручка связи центром на правом нижнем углу выбранной ноды (у нижнего/правого края сцены — на верхнем/левом),
  а не под нодой; порог показа HANDLE_MIN_ZOOM = 0.75 (было 0.5). Тест: ручка 20 и 24 px при 0,75/1/1,5/2 не
  пересекает ни одного из 8 соседей сетки, в том числе у краёв сцены.
- C11 = C27: ручка не рисуется в окне уже 1100 px (там детали — модальный лист, колонка со сценой inert, ручка была
  бы видна, но недоступна). Подсказка GraphHint описывает рабочий способ по указателю и ширине: касание — удержание
  записи → «Связать с…»; мышь ≥ 1100 px — значок связи или Shift+перетаскивание; мышь уже 1100 px — правая кнопка →
  «Связать с…» или Shift+перетаскивание. Одна ветка вместо двух абзацев (pointer-coarse на CSS убран).
- C28: у ноды под курсором клавиатуры — подсказка сразу (без задержки), если мышь ни на чём не наведена; не для ноды,
  открытой в деталях (selectedId === cursorId), не на касании, не у ноды за краем сцены. Чистая tooltipTarget + тест.
- M4: handleBox возвращает null, если квадрат ноды целиком за краем сцены (ручка не прилипает к краю).
- M15: GraphHint скрыт, пока linkFrom !== null или pickerFor !== null (подсказка закрывала строку режима связи).
- M16: у подписи в пиксельных сценах вертикальный запас под контур (pixel:py-0.5; truncate обрезал выносные элементы);
  ширина для pickLabels — по реальному шрифту (canvas measureText по computed-стилю контейнера, вес --fw-m в
  пиксельных сценах, разрядка, кеш; пересчёт по subscribeGraphTheme и document.fonts.ready; без canvas — оценка по
  кеглю). text-xs перенесён с подписей на контейнер, чтобы читать кегль.
- C3, подключение: pickLabels получает core = visibleBounds(v).
- M20: у GraphToolbar убраны вторые отступы safe-area (остались bottom-2 left-2).
- Замечание приёмки: счётчик в GraphHeader — shrink-0 + whitespace-nowrap; h1 shrink-0; подсказка клавиш сжимается и
  усекается раньше счётчика.
- M18 п.3: справка диктору (GraphA11y HELP) дополнена: Esc — снять курсор, Shift+F10 — действия с записью; про Tab
  написано «по связям записи (после последней связи фокус уходит дальше по странице)» — под решение по C24.
- M19 (часть): у строки режима связи убран role="status" (живая строка GraphA11y уже объявляет режим).
