## Результат

Спецификация — `.progress/spec-stage8.md` (12 разделов: что есть в коде, решения Р1–Р12, волна 0, логика, интерфейс,
долги, документация, CI, пакеты, проверка основной сессией, приёмка Windows, HANDOFF, открытые вопросы).

Главное, что выяснено по коду:
- Поиск, резервная копия и экспорт Markdown уже работают с `ocrText`; интерфейса для распознанного текста нет вовсе.
- `aiAutoOcr` и `aiVisionModel` в настройках есть, но нигде не используются; в копию не попадают.
- pdf.js 6.5.438 декодирует JBIG2, CCITT и JPX модулем из `wasmUrl`; он не задан, а WebAssembly запрещён CSP —
  чёрно-белые офисные сканы растеризовались бы пустыми. Решение: JS-варианты декодеров (`useWasm: false`), файлы
  кладёт свой плагин Vite, CSP не меняется.
- `ItemMenu` рисуется в каждой карточке — пункт «Распознать» туда не добавляется (нужна была бы подписка на
  настройки в каждой карточке).
- Мини-окно прячется сразу после сохранения — зрение в нём не запускается, запись подхватывает главное окно.

Ключевые решения: `Item.ocrVisionAt`; `Settings.aiAutoOcrSince` (авто только для записей, созданных после включения);
запрос с изображением — `ai.recognizeImage` (единственная точка отправки, первой строкой проверяет «ИИ включён»);
три вида ошибок (config / item / transient); очередь с параллельностью 1, паузой 3 с и пределом 100 автозапросов за
сеанс; схема Dexie и версия копии не меняются; расширение — в установщик через `bundle.resources`.

Пакеты: волна 0 — `ocr-data`, затем `ocr-facade` (оба opus); волна 1 — `ocr-logic` (opus), `ocr-ui` (sonnet),
`debts-search` (opus), `debts-ui` (sonnet), `ext-bundle` (opus), `docs-user` (sonnet), `docs-claude` (sonnet),
`ci` (sonnet). Файлы не пересекаются.

Не проверено (нечем на этапе проработки): растеризация сканов в WebView2 с JS-декодерами, форма записи
`bundle.resources` для каталога (исполнитель сверяет по `tauri-utils` и `cargo check`), точные параметры
`page.render` в pdf.js 6.5 (сверить по типам пакета), поведение провайдеров на запрос с `image_url` (таблица
ошибок составлена по типовым ответам).
