# stage3-list

Задача: пакет «list» этапа 3 (ItemList, ItemCard, EmptyState, BulkBar, ItemMenu) в пиксельный стиль; «Классика» без отличий.
Статус: готово

## Результат
- Строка: флажки избранного/статуса, полоса категории (`px-catbar`, `catBarStyle`), значок типа 30px, категория над временем,
  квадратные кнопки действий, меню «…» с `px-btn`, `data-checked`. Обёртка тела в «Классике» — `display: contents`.
- Карточка сетки: `px-row`, полоса категории элементом, накладки с рамкой; быстрые кнопки в накладке без `px-btn` (проп `dense`).
- Долг ревью: `StarMark` в карточке — золотая плашка с рамкой wood-dark, значок `gold-ink`; в строке скрыт в П.
- ItemList, EmptyState, BulkBar (`px-pop`), ItemMenu (триггер card `pixel:size-7.5`, на тач-экранах 36px) — по §2.2.
- Рецепт `pixel:text-inherit` из QuickButton убран.
- typecheck и test зелёные; grep по файлам чист (кроме разрешённого `text-[0.8rem]` в BulkBar).

## Не проверено
- Сверка «Классики» была по вычисленным стилям строк (342 узла, 1024 и 375px, свет; сетка снималась, но не сверялась поэлементно):
  отличий нет, кроме текстов времени. Базовый снимок кнопок был снят в момент transition (радиус 0/вес 700), поэтому
  по кнопкам сверка косвенная: классы `px-btn`/`pixel:*` в «Классике» не действуют.
- Не проходил вручную все клавиши и массовые действия (проверены J, Esc, F, Ctrl+клик, BulkBar виден); «Луг», «Бумага» — не смотрел;
  «Зима» день — только архив, меню в момент анимации; «Осень» день/ночь, «Классика» 1280 как таковой — не снимал (1024 и 375).
- «Мягкий пиксель»/«Пиксельный»: переполнения строк нет по DOM, на глаз виден только «Пиксельный» в архиве.
- Тулбар BulkBar на 390px глазами не смотрел.
