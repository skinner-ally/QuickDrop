Статус: готово

## Результат
- `NavButton.tsx` (нов.): `NavButton` и `SectionHeader` перенесены из `Sidebar.tsx` без изменений; добавлен необязательный проп `title`.
- `Sidebar.tsx`: «Корзина» после «Архива» (счётчик `useTrashCount`, обычный, скрыт при нуле); `<SavedSearches />` между разделами и «Категориями».
- `SavedSearches.tsx` (нов.): секция «Поиски» (сворачиваемая, пусто → ничего), строка с подсказкой-запросом, активный поиск (запрос в строке совпадает, фильтры пусты), меню «Переименовать / Выше / Ниже / Удалить» (края отключены), переименование на месте (Enter/blur — `actRenameSearch`, при ошибке поле остаётся; Esc — отмена).

- Клик по поиску: раздел «База знаний», запрос в строке, подсветка строки. Клик по «Корзине»: `view === 'trash'`, `#/trash`, пункт подсвечен.
