# stage6-amb-sprites

Задача: пакет «amb-sprites» этапа 6 (волна 1, spec-stage6 §5.1) — процедурная графика сцен в Uint32Array:
`src/lib/ambient/sprites/{build,palette,forest,ground,index}.ts` и `sprites.test.ts`. Экспорт `buildSceneArt(scene, dark, lod, soft)`.

Статус: готово

## Результат
- `build.ts`: `makeSprite` (контур 1 px, овальная тень, опора), `ellipse`, `crown` (перенос из mockup/forest.js),
  `downscale(s, 2|4, minShare=0.5)` (самый частый цвет блока, при равенстве — более тёмный; опора делится),
  `nightColor` (яркость ×0.5, затем насыщенность ×0.85 — матрица фильтра), `soften`, `mapColors`, `paintedCount`.
- `palette.ts`: `GROUND` (восемь значений = `--ground`), гаммы листвы/хвои, вода, тени, кора, камень, цвета мелочи по
  сценам (SCENES мокапа; добавлены чернила клякс «Бумаги»).
- `forest.ts`: `buildForest(scene, dark)` — 4 гаммы × 3 кроны, сосны ×2, кусты 4×2, камни ×2, мелочь ×3, камыш ×3,
  кувшинка ×2 (зимой `null`), цвета воды; ночь — `nightColor` от дневных цветов.
- `ground.ts`: `buildGround(scene, dark)` — мелочь по долям r1 (Луг 0.50/0.32/0.04; Осень 0.14/0.08/0.32 + листья
  3 формы × 4 цвета 0.09 + гриб 0.01; Зима 0.06/0.32/0.20/0.09; Бумага: волокна 0.17, 2 кляксы 0.004), `grid` — точка
  1×1 «Бумаги»; ночные цвета мокапа; опора — центр, размеры ≤ 6×6; `DETAIL_SHARE` — суммарные доли по сценам.
- `index.ts`: `buildSceneArt` (базовые спрайты кэшируются на сцену и яркость; lod 1/2 — уменьшение базовых; для lod 2
  при потере тонких деталей (камыш) — два шага по 2; смягчение к земле лениво с memo; `soft` ограничивается 0..0.5;
  «Бумага» — `object → null`, `water → null`; на lod ≥ 1 `detail`/`grid` → `null`). Реэкспорт `downscale`, `nightColor`,
  `soften`, `GROUND`, `DETAIL_SHARE`.

## Тесты
- `sprites.test.ts` (43): GROUND = `--ground` всех восьми вариантов (`readSceneCss`), размеры ≤ SPRITE_LIMITS и опора
  (центр ширины, нижние 4 строки) для всех видов/гамм/вариантов/сцен/яркости; мелочь и узор ≤ DETAIL_LIMIT с опорой в
  центре; опора внутри спрайта на lod 1/2; состав сцен (кувшинок зимой нет, «Бумага» без объектов и воды); детерминизм
  (повторная сборка побайтно); доли мелочи ±0.02 на 10 000 значений r1 и по видам «Луга»; r2 выбирает вариант (12
  вариантов листьев); ночь темнее (объекты, вода, мелочь); `soft = 0.5` снижает наибольший контраст к земле; lod 1 —
  ceil(w/2)×ceil(h/2), lod 2 — ceil(w/4)×ceil(h/4), пустых нет; `downscale`; нет пикселей с альфой 0 и цветом ≠ 0.
- `npm run typecheck` — чисто; `npm test` — 72 файла, 2132 теста (на момент прогона), все прошли; после косметического
  переименования функции в build.ts повторно прогнан typecheck и тесты пакета — чисто.
