# spec-stage7 — архитектор этапа 7 (быстрый захват)

Статус: готово
Дата: 2026-11-13

## Задача
Сверить часть 2 `.progress/spec-tauri.md` с нынешним кодом (после этапов 1–6) и решениями основной сессии,
дописать §2.14 «Исполнение этапа 7», разбить на пакеты. Код не менялся, git не трогался, ничего не устанавливалось.

## Результат
Изменён один файл: `.progress/spec-tauri.md` (часть 2: 36 пометок «(уточнено перед этапом 7)», новый §2.14,
пп. 2.14.1–2.14.11). При расхождении пп. 2.1–2.12 с п. 2.14 действует п. 2.14.

### Что исправлено в части 2
- `closeToTray` по умолчанию `false` (в `src/types.ts` сейчас `true` — меняет пакет `contracts`); разового вопроса
  при первом закрытии, события `tray-hint` и ключа `qd-tray-hint` нет.
- Скрытое мини-окно не даёт процессу завершиться при закрытии главного окна → на `Destroyed` окна `main`
  вызывается `app.exit(0)`.
- Новая настройка `captureWindow` (умолчание `true`); мини-окно создаётся командой `set_shell_options`, а не
  `prepare_capture_window`; при выключенной настройке окно уничтожается. Размер окна 640×440.
- Автозапуск — командами Rust `get_autostart` / `set_autostart` поверх плагина; npm-пакет и права `autostart:*`
  не нужны, `package.json` не меняется; запрет в отладочной сборке проверяет Rust.
- Канал расширения: очередь с подтверждением (`ext_take_pending` / `ext_capture_done`) вместо события с данными;
  `Host` только `127.0.0.1:{port}`; `Origin` обязателен для POST и OPTIONS, строго `chrome-extension://` + 32
  буквы; предел 30 запросов за 10 с (429); идентификатор записи наружу не отдаётся; сроки 5 с + 10 с,
  расширение ждёт 20 с; смена порта не роняет работающий сервер.
- Расширение: права без `scripting` (выделение — из `info.selectionText`, без переносов строк); у `link` нет
  заголовка; значки делает скрипт; service worker — ES-модуль с общим `shared.js`.
- Приём записей — отдельный `src/lib/extInbox.ts`, подключается из `main.tsx`; форма мини-окна повторяет
  жизненный цикл диалога (монтируется на показ, размонтируется на скрытие).
- Риски: глобальный `listen()` получает события чужого окна; `settleStaleLinkMeta` во втором окне;
  `tiny_http` и `tauri-plugin-autostart` локально не скачаны (API записан по памяти, сверяет `deps`).
