# stage6-amb-engine

Задача: пакет «amb-engine» этапа 6 (волна 0, spec-stage6 §4.6) — слой `AmbientLayer` (`src/lib/ambient/engine.ts`)
с тестами (`engine.test.ts`).

Статус: готово

## Результат
- `engine.ts`: `Surface`, `EngineDeps`, `AmbientEngine`, `createAmbientEngine` — сигнатуры по §4.6, добавлений нет.
  Поток draw: поляны (по sceneRev; новая ревизия `clearRev` только при другом `key`/`size`) → тик `scheduler.consume`
  → плитки (от центра экрана, ключ `artKey|step.key|ti,tj`, бюджет 10 мс с ценой прошлой плитки, первая — всегда,
  отложенные → `requestFrame`) → запас-кольцо → `store.trim` → пары эффектов → сведение back/front только при
  изменениях → `setRunning(animate && (эффекты || растворения))`.
- Растворение: `'lighter'`, `p = ceil(3·(time − t0)/250)/3`, при `p >= 1` старая — release; плитка ушла с экрана
  или со ступени — release сразу; повторная смена во время растворения — прежняя старая release.
- `configure`: смена сцены — `store.clear()`, кэш графики и растворения сброшены; `animate:false` — планировщик стоп,
  растры эффектов и растворения освобождены, front и under очищаются следующим draw.
- `dispose`: release плиток, растворений, растров эффектов; `scheduler.setRunning(false)`; дальнейшие draw — пусто.

## Решения на свободе спецификации (записаны в отчёт как deviations)
- Кольцо: проверка памяти — пиксели плиток, взятых в этом кадре (видимые + готовые кольца) + недостающие кольца
  ≤ AMBIENT_TILE_MAX_PX, а не `store.pixels` (после прыжка в кэше ещё лежат старые плитки до trim).
- Устаревшие (по подписи) плитки кольца перерисовываются в бюджете без растворения, прежняя — release.
- До `configure`, при `pixel:false` или нулевом canvas: очистка (на первом кадре canvas считается «рисованным»),
  растворения освобождаются, планировщик стоп.
- `EffectFrame.near` — `clearing.near`, если хост дал `points`, иначе `frame.nodeNear`; `bounds` — экран ± 64·dpr px.
- `dispose` не зовёт `scheduler.dispose()` (по спецификации — только `setRunning(false)`; планировщик — у контроллера).

## Тесты (`engine.test.ts`, 23)
Целые координаты и масштаб плиток на 7 ступенях × dpr 1/1.25/1.5/2; повторный draw после кольца — ноль вызовов
контекста и поверхностей; сдвиг на полплитки — только новые плитки кольца; кольцо сверх предела памяти (4096×3072,
k = 0.5) не рисуется и кадр не просится; цена 5 мс — ровно 2 ближние к центру плитки и requestFrame, дорисовка по 2
за кадр до конца; sceneRev с теми же точками — ноль отрисовок; перенос точки — заново ровно плитки со сменившейся
подписью, старые release; 300 прыжков — tilePixels ≤ предела, живы только поверхности кэша; смена сцены;
растворение 1/3 → 2/3 → release, планировщик стоп; растворение ушедшей плитки; animate:false; пустой список
эффектов; тик → только front; пара world со сдвигом и перерисовка при смене k; пара under; configure(animate:false);
dispose; pixel:false; нулевой canvas; смена размера (растр с прежним t); кэш графики; EffectFrame.
`npm run typecheck` — чисто; `npm test` — 70 файлов, 2074 теста, все прошли.
