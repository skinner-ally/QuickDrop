# stage6-amb-tiles

Задача: пакет «amb-tiles» этапа 6 (волна 0, spec-stage6 §4.4, §4.5) — плитка в растр (`src/lib/ambient/tileRender.ts`)
и кэш плиток LRU (`src/lib/ambient/tileStore.ts`) с тестами.

Статус: готово

## Результат
- `tileRender.ts`: `TILE_MARGIN_PX = 40`, `CLEAR_REACH = 360`, `renderTile`, `tileSignature` по §4.4.
  Порядок: узор сетки (lod 0 и клетка графа >= 8 пикселей решётки, полянами не убирается) → мелочь земли (lod 0,
  пропуск ближе `CLEAR_GROUND_R` к ноде) → пруды по пикселям решётки в `pondBox ∩ плитка` (центр пикселя в мире,
  `pondDistance`; shore/bank/lit/mid/deep, блики `dash` — правило мокапа по арт-координатам, только lod 0 и q < 0.84)
  → объекты леса без `objectCleared` + камыши/кувшинки нескрытых прудов, сортировка `compareObjects` (y, x, id).
  Всё ставится по опоре: `toLattice(step, x) − ax − ti·size`. Растр не того размера — не ошибка (рисуется с угла
  плитки, обрезается по out). Возвращает число объектов (лес, камыши, кувшинки), задевших out (мелочь и узор не в счёте).
- `tileStore.ts`: `createTileStore` по §4.5. Map в порядке вставки; `trim` — по возрастанию `used` (при равных —
  положенная раньше), записи с `used === frame` не трогает; запись убирается из кэша до `release`.
  `put` на существующий ключ возвращает прежнюю поверхность без `release`; если поверхность та же самая — `undefined`
  (её нельзя освобождать). Негодное `pixels` считается нулём.

## Тесты
- `tileRender.test.ts` (27): 2×2 соседние плитки побайтно равны одной «большой» (та же ступень, сторона ×2) на k = 1,
  1.25, 0.5, 0.25, 0.125, в отрицательных индексах, с нодами у шва; повтор (и после чужих плиток, и после сброса кэша
  мира); порядок объектов совпадает с эталонной раскладкой (обратный — нет); поляны на k = 0.125/0.5/1/1.25/2: нода в
  центре плитки + случайные ноды, ни одного пикселя, кроме узора сетки (объекты, мелочь и вода), ближе 24 − worldPerPx
  к квадрату 16×16 (замер: наименьшее 28–38 px), узор у нод остаётся на lod 0, на lod 2 его нет; без нод у центра
  есть пиксели ближе 24 (проверка не пустая); пруд у ноды скрыт вместе с камышами/кувшинками, за reach — на месте;
  пруд в своей рамке всеми цветами воды; блики только на lod 0; мелочь и узор только на lod 0, узор — при клетке ≥ 8 px;
  water = null и object = null — пустая плитка; растр другого размера и 0×0; tileSignature (пустая — 0, меняется при
  переносе ближней, не меняется при переносе далёкой; ноды сразу за радиусом влияния не меняют растр); скорость.
- `tileStore.test.ts` (12): LRU по used, равные used, записи текущего кадра не вытесняются, release ровно один раз,
  put на существующий ключ, та же поверхность, clear, согласованность size/pixels на 400 случайных операциях.
- Скорость в node (лучшее из 3 после сброса кэша мира, с 40 нодами): k = 0.5 (u 1, lod 0) ≈ 3.0 мс, 94 объекта;
  k = 0.125 (u 1, lod 2) ≈ 2.2 мс, 1632 объекта. Порог теста — 30 мс.
- `npm run typecheck` — чисто; `npm test` — 69 файлов, 2051 тест, все прошли.
