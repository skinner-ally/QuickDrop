## Главные решения
- Фон в решётке устройства: пиксель графики — целое число пикселей устройства, плитки — блоки решётки (швов нет при
  любом dpr); на мелком масштабе — уменьшенные спрайты (lod) и смягчение цветов к земле.
- Поляны — чистая структура из точек нод (рамка вокруг объекта, круг вокруг пруда и мелочи земли); плитка
  перерисовывается только при смене набора нод в радиусе влияния, смена — растворением в 3 шага.
- Эффекты — растры низкого разрешения, ≈12 кадров/с; планировщик без собственного rAF, тик взводится только после
  нарисованного кадра.
- Режимы: off (не «Граф», фон выключен, «Классика»), static (reduced-motion, скрытое окно), animated.
- pixelfx: ядро не переносится; в `src/lib/pixelfx` — помощники, листопад и лучи с LICENSE; снег, светлячки, бабочки — свои.
