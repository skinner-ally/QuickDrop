# stage5-graph-nav

- Задача: пакет «graph-nav» этапа 5 (волна 1) — пункт «Граф» в боковой панели, клавиша 5, команды палитры, строки
  в «Горячих клавишах». Спецификация — `.progress/spec-stage5.md` §0 (Р13, Р14, Р17, Р20), §3.1, §3.2, §4.0, §4.5, §5.
- Статус: готово

## Результат

- `Sidebar.tsx`: «Граф» пятым перед «Корзиной», без счётчика (`count` необязателен); в разделе «Граф» клик по категории
  («Без категории» тоже) и по тегу ставит/снимает фильтр (`setFilter({categoryId|tags: …/undefined})`), раздел не
  меняется; подсветка и `aria-pressed` — как в «Базе знаний». Вне графа поведение прежнее.
- `useHotkeys.ts`: `Digit5: 'graph'`.
- `CommandPalette.tsx`: «Перейти: Граф» после «Перейти: Архив»; только в графе — «Граф: показать весь», «Граф: разложить
  заново», «Граф: показать/скрыть архив»; категория и тег из палитры в графе оставляют в графе (`toLibrary` не меняет
  раздел при `view === 'graph'`).
- `ShortcutsSection.tsx`: строка разделов 1–5, строки «На графе: …», дополнено описание секции.
- Проверено: `npm run typecheck` чист, `npm test` — 54 файла / 1737 тестов зелёные. В браузере (порт 5187, «Осень» и
  «Классика», 1280 по умолчанию и 390 px): клавиша 5 и 1; активный пункт «Граф»; категория, «Без категории» и тег в
  графе ставят и снимают фильтр, раздел остаётся «graph», пункт подсвечивается (`aria-current`/`aria-pressed`); вне
  графа категория открывает «Базу знаний»; палитра: «Перейти: Граф» везде, команды графа только в графе, выбор
  категории не уводит из графа, архив переключается (`showArchive` true → false, подпись меняется); строки в «Горячих
  клавишах» видны; 390 px — пункт «Граф» в выезжающем меню, горизонтальной прокрутки нет.

## Отклонения

- В палитре в графе пункт поиска сказал бы «в базе знаний», но (из-за правки `toLibrary`) остаётся в графе —
  подпись в графе заменена на «Искать «…» на графе». Вне графа без изменений.
