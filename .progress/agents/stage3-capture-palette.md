# stage3-capture-palette

Задача: перенос QuickCapture и CommandPalette в пиксельный стиль (spec-stage3 §2.6, §4.6) + замена window.confirm в snapshotRef вопросом внутри панели.
Статус: готово

## Результат
- QuickCapture: data-skin="panel", заголовок «Быстрая запись» с ростком (в К sr-only), прокрутка формы в П, чипы типа px-chip, FileRow px-well, квадратные кнопки (скрепка, звезда, «+», убрать файл) px-btn pixel:size-7.5 / max-md:size-9, оверлей перетаскивания pixel:bg-paper.
- Исправление поведения: window.confirm убран. snapshotRef при прикреплённых файлах возвращает false и показывает в панели строку role="alert" «Прикреплённые файлы не сохранятся. Закрыть?» с кнопками «Закрыть» (закрывает, текстовый черновик пишется как раньше) и «Остаться» (получает фокус). Повторный Esc / клик вне при показанном вопросе = «Остаться». Вопрос исчезает при изменении списка файлов.
- CommandPalette: Command pixel:p-0, строка подсказок pixel:border-t-2 pixel:px-1, шесть действий «Сцена: …» (useScene().setScene + setSetting('scene')), комментарий-заглушка для этапов 4-5 после go-archive (на месте go-settings).

## Проверено (DOM и вычисленные стили, порт 5186; в iframe нужной ширины, т.к. эмуляция окна не меняла media queries)
- typecheck и npm test (1242) зелёные; grep по файлам: lucide-react, text-[, hex, oklch( не найдены.
- Классика (светлая): вычисленные стили диалога, textarea, чипов типа и кнопок до и после правок совпали (кроме заголовка sr-only «Быстрая запись» по спеке).
- Сценарий вопроса: Esc с файлом показывает вопрос и фокус на «Остаться»; второй Esc скрывает; добавление файла скрывает; «Закрыть» ставит диалог в закрытие (captureOpen=false), текстовый черновик в sessionStorage сохранён.
- Осень (день/ночь), Классика (день/ночь), Луг/Бумага/Зима (день), шрифты round/soft/pixel на 1200 и 390: рама-панель, градиент отсутствует, ничего не вылезает за диалог, форма помещается, подсказки скрыты на 390.
- Палитра: рама через :has, активная строка, стрелки по кругу (вверх с первой = последняя), фильтр «сцена: луг» + Enter сменил сцену и записал настройку, 390px помещается, подсказки скрыты.

- Скриншотов нет: панель браузера скрыта, снимки не снимаются; вид глазами не видел, только вычисленные стили и геометрия.
