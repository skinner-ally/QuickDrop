# review-ui-ui-quality

Задача: ревью этапа «интерфейс», линза «качество интерфейса» (дизайн, тёмная тема, мобильная вёрстка, доступность, русские тексты, производительность рендера). Только чтение.

Статус: готово

Изменённые файлы: только этот отчёт. Проверка — чтением кода (приложение не запускалось).

## Вердикт

Этап принимать с доработками. Блокирующих для десктопа дефектов нет, но мобильная версия (<768px) в текущем виде
не соответствует требованию «обязан работать на iPhone»: у разделов нет полей и есть горизонтальная прокрутка,
поля ввода зумят страницу, плавающая кнопка перекрывает действия. Тёмная тема и склонения числительных — без замечаний.

## Находки

### Высокие
1. **Разделы без полей + горизонтальная прокрутка на мобильном** — `views/ItemsView.tsx:53`, `views/InboxView.tsx:167`,
   `components/layout/AppShell.tsx:84`, `components/items/FilterBar.tsx:308`. Ни `<main>`, ни секции разделов не задают padding
   (только SettingsView). Заголовок, QuickAdd и панель фильтров прижаты к краям; FilterBar с `-mx-4 px-4` шире контейнера
   на 32px → `<main>` прокручивается по горизонтали.
2. **Зум страницы на iPhone при фокусе** — `index.css:175`. Правило `font-size:16px` лежит в `@layer base` и проигрывает
   утилитам: TagInput (`TagInput.tsx:149`, text-sm), CommandInput (`ui/command.tsx:77`), поиск тегов (`FilterBar.tsx:197`),
   адрес ссылки (`detail/LinkCard.tsx:133`), редактор кода (`detail/ContentEditor.tsx:69`), textarea кода (`QuickCapture.tsx:431`).

### Средние
3. FAB «Добавить» перекрывает BulkBar и меню последней строки — `layout/MobileNav.tsx:12,31`, `BulkBar.tsx:58`.
4. Планшет 768–1100px: сайдбар 232 + детали 460 фиксированы, списку остаётся от 76px — `AppShell.tsx:77,90`.
5. Во «Входящих» два комплекта сортировки и переключателя вида (шапка + FilterBar) — `InboxView.tsx:183-196`.
6. TagInput теряет набранный, но не подтверждённый тег; в BulkBar кнопка «Добавить» остаётся выключенной — `TagInput.tsx:137`, `BulkBar.tsx:100`.
7. Подсказки TagInput обрезаются внутри диалога QuickCapture (`overflow-y-auto`) — `TagInput.tsx:159`, `QuickCapture.tsx:626`.
8. `CategoryBadge` вызывает `useCategories()` (useLiveQuery) в каждой строке списка — `CategoryBadge.tsx:24`.
9. `memo` строк не работает при любой записи в БД: сравнение `hit.item` по ссылке — `ItemCard.tsx:218`.
10. На тач-устройствах чекбокс выбора невидим (появляется только по hover), а тап по иконке типа выбирает запись — `ItemCard.tsx:246-271`.
11. Цели касания 20–28px: меню «…» строки (единственный доступ к действиям на таче), шапка деталей, чипы фильтров — `ItemMenu.tsx:99`, `ItemDetail.tsx:122`, `FilterBar.tsx:106,276,360`, `TagChip.tsx:56`.
12. Enter на сфокусированной строке списка ничего не делает, пока не нажат J/K — `ItemList.tsx:194-204`, `ItemCard.tsx:299-304`.
13. Мобильный лист деталей не модален: фокус не переносится, фон не inert — `AppShell.tsx:99-105`.
14. `role="listbox"/"option"` с вложенными кнопками, чекбоксом и меню — `ItemList.tsx:333`, `ItemCard.tsx:300`.
15. Счётчики категорий и тегов в сайдбаре считают входящие, а переход ведёт в базу знаний — `Sidebar.tsx:188-195`, `useItems.ts:86-99`.

### Низкие
16. Иконки без `strokeWidth={1.75}` и меньше 16px в кнопках sm/xs — `BulkBar.tsx:68-120`, `ItemDetail.tsx:123,138,143`, `InboxView.tsx:99,162,190`, `detail/LinkCard.tsx:94-107` и др.
17. `brand` вне разрешённых мест: ссылки, ключевые слова кода, выбранные строки, прогресс разбора, оверлей перетаскивания — `detail/AutoLinkText.tsx:68`, `CodeView.tsx:145`, `ItemCard.tsx:309,451`, `TriageMode.tsx:452`, `AppShell.tsx:115`.
18. Контраст: текст плашек категорий (amber/orange/pink ≈ 2–3:1), токены кода, заголовок-плейсхолдер `/70` — `CategoryBadge.tsx:34`, `CodeView.tsx:143-144`, `detail/TitleField.tsx:37`.
19. Английские строки: «Close» у кнопок закрытия диалога/листа, «Base URL» — `ui/dialog.tsx:75`, `ui/sheet.tsx:73`, `settings/AiSection.tsx:95`.
20. Подсказки про клавиши N и F в пустых состояниях показываются и на телефоне — `InboxView.tsx:146`, `FavoritesView.tsx:15`.
21. В QuickCapture нет кнопки закрытия: на таче закрыть можно только тапом мимо — `QuickCapture.tsx:625`.
22. Несогласованные термины: «Список/Карточки» и «Списком/Плиткой»; «ИИ» и «AI»; «Системная тема»/«как в системе»; «Сбросить»/«Сбросить фильтры»; «детали»/«подробности».
23. `prefers-reduced-motion`: бесконечные анимации (спиннеры, pulse) не останавливаются, нет `animation-iteration-count: 1` — `index.css:189-194`.
24. `theme-color` привязан к теме ОС, а не к выбранной в приложении — `index.html:8-9`.
25. Звезда избранного: янтарная в списке и разборе, цвета текста в деталях и добавлении — `ItemDetail.tsx:138`, `QuickCapture.tsx:561`.
26. Шесть разных оформлений `<kbd>` — `Sidebar.tsx:28`, `TopBar.tsx:55`, `TriageMode.tsx:50`, `CommandPalette.tsx:61`, `ShortcutsSection.tsx:7`, `InboxView.tsx:147`.
27. `role="radiogroup"` без стрелочной навигации — `settings/AppearanceSection.tsx:20`, `settings/CategoriesSection.tsx:47`.
28. Нигде не учтены `env(safe-area-inset-left/right)` (альбомная ориентация iPhone) — `AppShell.tsx:75`, `TopBar.tsx:19`.

## Проверено, замечаний нет
- Жёстко заданных цветов нет, кроме лайтбокса (`bg-black/90 text-white`, уместно). Градиентов, эмодзи, капса нет.
- Склонения числительных корректны (BulkBar, «ждут разбора»). «База знаний», «Входящие», «Архив», «Избранное» — единообразно.
- Подписок на весь zustand-стор без селектора нет. `100vh` не используется (везде `dvh`).
