# Предложения по правке CLAUDE.md (редизайн графа, 0.2.2, 2026-11-14)

Пользователь утвердил макет графа («Мокап утверждаю») и попросил перенести его в приложение и выпустить.
CLAUDE.md меняется только с его личного подтверждения; ниже — что в нём устарело после переноса.

## «Структура»
- `lib/` — добавить `pixelfx-kit/` (ядро pixelfx на JS, MIT, `LICENSE` и `NOTICE.md`; используется только сценой казни
  ноды: `core/index.js`, `fx/moves/node-smite.js`; типы — рядом, `*.d.ts`; линт его не проверяет — `.oxlintrc.json`).
- `lib/legacyGrid.ts` — перенос положений со старой сетки графа (32) на нынешнюю (48).
- `lib/devStress.ts` — только в dev: `window.__qdStress.seed(n)` / `.remove()` (1000 нод разных категорий с тегом «стресс»).
- `components/graph/` — `GraphSmite` (сцена казни поверх графа), `swarmDriver` (покадровый ход стаи).

## «Модель данных»
- «Схема Dexie — версия 2» → «версия 3»: v3 схему не меняет, upgrade переносит `positions` на сетку 48 (×1,5).
- `BACKUP_VERSION = 2 (читаются версии 1–2)` → `3 (читаются 1–3)`; у копий 1–2 положения при импорте
  переносятся на сетку 48 (`upgradeLegacyRawPosition`).

## «Контракты модулей»
- `lib/graphLayout.ts`: `GRAPH_NODE_SIZE = 24`, `GRAPH_CELL = 48` (были 16 и 32).
- `lib/actions.ts`: `actMoveGroup(moves, prev)` — перенос группы нод одним пакетом, toast «Перемещено N записей» с «Отменить».
- `lib/graph/swarm.ts` — стая при перетаскивании (пружины, задержка по расстоянию, `planSwarmDrop`, текст тоста);
  `lib/graph/smite.ts` — сцена казни при удалении ноды (стор `useSmite`, `smiteStruck`, `smiteFinished`);
  `lib/graph/draw.ts` — `drawSwarmTrails`; тема графа — `linkThin` (тонкая связь: контрастнее из `--graph-link`/`--graph-link-edge`).

## «Горячие клавиши» (граф)
- Перетаскивание ноды тянет за ней всю её категорию («медуза»); `Alt` — только одну ноду; запись без категории — одна;
  `Esc` во время переноса возвращает стаю.
- `Del` и пункт «Удалить» меню ноды — сцена казни (латник рубит ноду; в 35 % случаев нода уклоняется от первого удара);
  запись уходит в корзину в момент удара. При `prefers-reduced-motion` и больше трёх нод за раз — без сцены.
